# 第 1 章：线性代数——数据世界的底层语法


> **💡 工厂模式约定**：本章大量使用 `Linalg.vector()`、`Linalg.matrix()`、`Opts.lbfgs()` 等工厂类入口。
> 不需要记住具体实现类名——所有数学对象通过统一的工厂类创建，代码简洁且风格一致。


> **上课前**：如果你选修过线性代数，大概率感受是「会算行列式、会求特征值，但不知道这些玩意儿能干什么」。本章的目标就是把这个认知倒过来——**先告诉你这东西在产业里怎么用，再教你用代码实现它，最后再补理论**。学完之后，你看到用户-商品评分矩阵时，会本能地想到特征分解；看到文本向量化时，会想到奇异值分解。

## 读完本章你能做什么？

- 用矩阵分解给用户推荐他可能喜欢的商品（**推荐系统**）
- 用奇异值分解从海量特征中提取主成分，搞清楚哪些信号真正重要（**降维 / PCA**）
- 用线性规划给连锁奶茶店计算最优原料配比（**运筹优化**）
- 用主成分分析把银行贷款数据从 50 维压到 5 维，同时保留 95% 的信息量（**特征压缩**）
- 用条件数判断你的回归模型对异常值有多脆弱（**数值稳定性**）

这五条对应着本章五类核心算法的产业场景，每一种都是数据分析和决策的日常工作。

## 代码风格约定

本章所有代码示例遵循以下规范，与 YiShape-Math 库的设计保持一致：

```java
// ✅ 推荐：直接用 Linalg 工厂方法创建向量和矩阵
var x = Linalg.vector(new double[]{1.0, 2.0, 3.0});
var A = Linalg.matrix(new double[][]{
    {1.0, 0.0},
    {0.0, 2.0}
});

// ✅ 链式调用是正常写法，不是炫技
double result = A.multiply(x).add(b).sum();

// ❌ 避免：直接 new 具体实现类（RereDoubleVector 等）
```

> **为什么这样约定？** `Linalg.vector(...)` 背后会自动选择最优实现，而直接 `new` 会把你的代码写死——后续换实现时改到你怀疑人生。
