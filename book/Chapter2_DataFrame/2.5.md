
## 开场：为什么数据科学家说「80% 的时间都在清洗数据」？


> **📌 学习目标**
> - 掌握 `join()` 的四种类型（内/外/左/右）及连接键匹配
> - 能用 `melt()` / `pivot()` 实现长宽表互转
> - 能用 `apply()` 对列进行自定义变换

业界有一句话：**「数据科学家 80% 的时间在清洗数据，真正建模只占 20%。」**

这句话出自 DJ Patil（美国前首席数据科学家），背后有一个现实原因：

真实数据从来不干净——有缺失值（用户没填表单）、有异常值（传感器故障读出了 9999°C）、有格式不一致（日期有时是 `2024-01-01`，有时是 `1/1/24`）、有重复记录（同一用户注册了两次）。

机器学习模型对脏数据非常敏感：输入 garbage，输出一定是 garbage。**「垃圾进，垃圾出」（Garbage In, Garbage Out）是数据科学的第一定律。**

本节的目标：让你把 80% 的清洗工作时间变成可复用的**流水线（Pipeline）**代码——写一次，以后每次新数据来了，一键运行。

# 2.5 数据预处理流水线

## 2.5.1 流水线总览


> 📝 **历史故事**：SQL 的 GROUP BY 等价于 **Codd 的关系代数的「分组聚合」** 操作，但 PostgreSQL 的窗口函数（Window Functions）由 **SQL:2003** 标准首次引入——这比 GROUP BY 晚了 17 年。
实际项目中，数据很少是「干净 CSV（Comma-Separated Values，逗号分隔值）直接进模型」——通常要经过以下步骤：

```
原始 CSV
  ↓
① 加载：DataFrame.readCsv()
  ↓
② 探索：shape()、列类型、head（打印前几行）
  ↓
③ 清洗：删除无关列、过滤异常行、处理缺失
  ↓
④ 特征选择：slice() 选出建模需要的列
  ↓
⑤ 类型转换：toMatrix() → IMatrix
  ↓
⑥ 预处理：中心化、归一化（→ 第 1 章、第 5 章）
  ↓
⑦ 喂给 ML 模型（→ 第 5 章）
```

## 2.5.2 案例：员工离职数据预处理

**数据**（`attrition.csv`，1000 行，部分列如下）：

| 列名 | 类型 | 说明 |
|------|------|------|
| satisfaction_level | Numeric | 满意度 [0, 1] |
| last_evaluation | Numeric | 最近评估分数 [0, 1] |
| department | String | 部门 |
| salary | String | 薪资等级（low/medium/high） |
| left | Numeric | 是否离职（0/1，**标签列**）|

```java
DataFrame raw = DataFrame.readCsv("attrition.csv", ",", true);

// ========== ① 探索 ==========
System.out.printf("原始形状: %d 行 × %d 列%n",
    raw.getRowCount(), raw.getColumnCount());
// 输出：原始形状: 1000 行 × 10 列

List<String> colNames = raw.getColumnNames();
List<ColumnType> colTypes = raw.getColumnTypes();
for (int i = 0; i < colNames.size(); i++) {
    System.out.printf("  [%d] %-20s %s%n", i, colNames.get(i), colTypes.get(i));
}

// ========== ② 删除无关列 ==========
// 假设第 0 列是员工ID（字符串，无建模价值），用 sliceColumn 排除
DataFrame cleaned = raw.sliceColumn(1, raw.getColumnCount());  // 删第 0 列

// ========== ③ 标签列分离（最后一个问题：把 left 分出来） ==========
int nCols = cleaned.getColumnCount();
DataFrame features = cleaned.slice(null, "0:" + (nCols - 1));  // 特征：前 n-1 列
DataFrame labels   = cleaned.slice(null, String.valueOf(nCols - 1) + ":");  // 标签：最后一列

// ========== ④ 只取数值特征列（用于 IMatrix） ==========
// 先找出所有数值列的索引
List<Integer> numericColIndices = new ArrayList<>();
for (int i = 0; i < features.getColumnCount(); i++) {
    if (features.get(i).getColumnType() == ColumnType.Numeric) {
        numericColIndices.add(i);
    }
}

// 用 sliceColumn 按索引列表选列（sliceColumn 不支持列表，改为逐个构建）
DataFrame numericFeatures = features.sliceColumn(0, 1);  // 先取第一列
for (int i = 1; i < numericColIndices.size(); i++) {
    // 追加第 numericColIndices.get(i) 列 → 依次 addColumn
    Column c = features.get(numericColIndices.get(i));
    Column cCopy = new Column();
    cCopy.setName(c.getName());
    cCopy.setColumnType(c.getColumnType());
    cCopy.setData(new ArrayList<>(c.getData()));
    numericFeatures.addColumn(cCopy);
}

// ========== ⑤ 转 IMatrix ==========
IMatrix X = numericFeatures.toMatrix();  // [1000, 8] — 8 个数值特征
var y = labels.get(0).toVec();  // 标签向量

System.out.printf("特征矩阵: %d × %d, 标签向量: %d%n",
    X.getRowNum(), X.getColNum(), y.length());
```

## 2.5.3 类别特征编码（One-Hot）

字符串列（如 `department`、`salary`）不能直接喂给线性模型或神经网络，需转为数值。最常用：**One-Hot 编码**——YiShape-Math 本身不提供 One-Hot 工具，但结合 `IMatrix` 可以手动实现：

```java
// 假设 salary 列是 low/medium/high
Column salaryCol = df.getColumnByName("salary");
List<String> uniqueVals = salaryCol.toStringList().stream().distinct().toList();
// uniqueVals = ["low", "medium", "high"]

// 构建 One-Hot 矩阵：每一行 → [1 if low else 0, 1 if medium else 0, 1 if high else 0]
int nRows = df.getRowCount();
int nCats = uniqueVals.size();
double[][] oneHotData = new double[nRows][nCats];

for (int i = 0; i < nRows; i++) {
    String val = salaryCol.toStringList().get(i);
    int idx = uniqueVals.indexOf(val);
    oneHotData[i][idx] = 1.0;
}

IMatrix oneHot = Linalg.matrix(oneHotData);  // [1000, 3]

// 拼接回原有数值特征矩阵
IMatrix Xaug = X.appendColumns(oneHot);      // IMatrix.appendColumns 要求形状行数一致
System.out.printf("拼接后特征矩阵: %d × %d%n",
    Xaug.getRowNum(), Xaug.getColNum());
```

> **说明**：`IMatrix.appendColumns(other)` 将两个**行数相同**的矩阵左右拼接，等价于 numpy 的 `np.hstack([X, oneHot])`。

## 2.5.4 缺失值处理

CSV 中空字符串 `""` 在读取时保留为 `""`（字符串列）或解析失败导致整列变 String 类型。处理策略：

```java
// 策略1：删除含缺失的行（按行切片）
DataFrame df = DataFrame.readCsv("housing.csv");
// 找出所有非空数值列 → 要求每行完整
List<Integer> completeRows = new ArrayList<>();
outer:
for (int r = 0; r < df.getRowCount(); r++) {
    for (int c = 0; c < df.getColumnCount(); c++) {
        String val = df.get(c).toStringList().get(r);
        if (val == null || val.trim().isEmpty()) continue outer;
    }
    completeRows.add(r);
}
// 取完整行
String rowRange = completeRows.stream()
    .map(String::valueOf)
    .collect(Collectors.joining(","));
// 实际生产中建议：先用 List<Integer> 收集，再生成 "0:10" 这样的表达式

// 策略2：用列均值填充数值缺失（更常见）
Column col = df.getColumnByName("age");
var ageVec = col.toVec();
double meanAge = ageVec.mean();

// 构建新列，缺失处填均值，其余不变
List<Object> filled = new ArrayList<>();
for (Object v : col.getData()) {
    if (v.toString().trim().isEmpty()) {
        filled.add(meanAge);
    } else {
        filled.add(v);
    }
Column filledCol = new Column();
filledCol.setName("age_filled");
filledCol.setColumnType(ColumnType.Numeric);
filledCol.setData(filled);
```

import com.yishape.lab.math.ml.ML;
import com.yishape.lab.math.ml.cls.ClassificationResult;

// 继续上例：用 X（特征矩阵）和 String[] 标签训练逻辑回归

## 本节小结

分组聚合（groupBy + agg）是数据分析的核心操作——将数据按类别分组后，对每组分别计算统计量。相当于 SQL 的 GROUP BY，是数据摘要的标准工具。

**核心要点**：groupBy 将数据划分为不重叠的组；agg 支持 sum/mean/count/max/min 等聚合函数；多级分组用 List<String> 指定多个列名。

## 本节 API 一览

| 场景 | API | 说明 |
|------|-----|------|
| Pipeline构建 | `Pipeline.of(steps...)` | 链式数据处理 |
| fit+transform | `pipeline.fit(train).transform(test)` | 先训练再转换 |
| 一步到位 | `pipeline.fitTransform(data)` | 训练集一次性处理 |
| One-Hot编码 | `DataFrame.oneHot(column, categories)` | 类别特征向量化 |
| 缺失值填充 | `df.fill(value)` 或 `df.fillNull("mean")` | 数值/类别分别处理 |
| 训练测试划分 | `ML.trainTestSplit(X, y, testRatio)` | 随机划分 |
| Pipeline导出 | `pipeline.save(path)` | 持久化复用 |

> **最佳实践**：始终用Pipeline封装预处理，保证训练/测试集用完全相同的处理步骤。
