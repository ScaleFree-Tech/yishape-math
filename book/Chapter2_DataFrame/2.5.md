
## 开场：为什么数据科学家说「80% 的时间都在清洗数据」？


> **📌 学习目标**
> - 掌握缺失值清洗的三种 API：`dropNa()`、`fillNa(double)`、`fillNaWithMean()`
> - 能用 `selectByType` / `selectByName` / `selectColumns` 快速选出特征列
> - 学会自己实现 One-Hot 编码（库内无现成工具）并拼回特征矩阵
> - 能用 `standardize()` / `normalize()` 完成标准化预处理

业界有一句话：**「数据科学家 80% 的时间在清洗数据，真正建模只占 20%。」**

这句话出自 DJ Patil（美国前首席数据科学家），背后有一个现实原因：

真实数据从来不干净——有缺失值（用户没填表单）、有异常值（传感器故障读出了 9999°C）、有格式不一致（日期有时是 `2024-01-01`，有时是 `1/1/24`）、有重复记录（同一用户注册了两次）。

机器学习模型对脏数据非常敏感：输入 garbage，输出一定是 garbage。**「垃圾进，垃圾出」（Garbage In, Garbage Out）是数据科学的第一定律。**

本节的目标：让你把 80% 的清洗工作时间变成可复用的**流水线（Pipeline）**代码——写一次，以后每次新数据来了，一键运行。

### 缺失值的三种面孔：你真的了解"缺失"吗？

在动手清洗之前，先问一个关键问题：**数据为什么会缺失？** 这不是哲学问题——不同的缺失机制决定了完全不同的处理策略。

| 缺失机制 | 全称 | 含义 | 例子 | 正确处理 |
|----------|------|------|------|----------|
| **MCAR** | Missing Completely At Random | 缺失与任何变量无关，纯随机 | 实验设备随机故障 | 直接删除或均值填充，偏差最小 |
| **MAR** | Missing At Random | 缺失与其他**已观测**变量有关 | 年轻人更不愿填收入→缺失与年龄有关 | 用其他列建模预测缺失值 |
| **MNAR** | Missing Not At Random | 缺失与**缺失值本身**有关 | 高收入者不愿透露收入→缺失与收入本身有关 | 最棘手，需要领域知识或敏感性分析 |

> ⚠️ **最常见的错误**：用 0 填充所有缺失值。0 是一个有含义的数字——「收入 = 0」和「收入未知」完全不同。0 填充会人为压低均值、扭曲分布，让模型学到错误的模式。

**YiShape-Math 提供三种安全的缺失值处理 API**：

```java
// 1. 直接删除含缺失值的行（适合 MCAR，且缺失比例 < 5%）
DataFrame noNa = df.dropNa();

// 2. 用固定值填充（适合已知缺失含义的场景）
DataFrame filled = df.fillNa(0.0);  // 用 0 填充所有数值列的缺失

// 3. 用列均值填充（适合 MAR，最常用的默认策略）
DataFrame meanFilled = df.fillNaWithMean();
```

# 2.5 数据预处理流水线

## 2.5.1 流水线总览


> 📝 **历史故事**：SQL 的 GROUP BY 等价于 **Codd 的关系代数的「分组聚合」** 操作，但 PostgreSQL 的窗口函数（Window Functions）由 **SQL:2003** 标准首次引入——这比 GROUP BY 晚了 17 年。
实际项目中，数据很少是「干净 CSV（Comma-Separated Values，逗号分隔值）直接进模型」——通常要经过以下步骤：

```
原始 CSV
  ↓
① 加载：DataFrame.readCsv()
  ↓
② 探索：shape()、列类型、head（打印前几行）
  ↓
③ 清洗：删除无关列、过滤异常行、处理缺失
  ↓
④ 特征选择：slice() 选出建模需要的列
  ↓
⑤ 类型转换：toMatrix() → IMatrix
  ↓
⑥ 预处理：中心化、归一化（→ 第 1 章、第 5 章）
  ↓
⑦ 喂给 ML 模型（→ 第 5 章）
```

## 2.5.2 案例：员工离职数据预处理

**数据**（`attrition.csv`，1000 行，部分列如下）：

| 列名 | 类型 | 说明 |
|------|------|------|
| satisfaction_level | Numeric | 满意度 [0, 1] |
| last_evaluation | Numeric | 最近评估分数 [0, 1] |
| department | String | 部门 |
| salary | String | 薪资等级（low/medium/high） |
| left | Numeric | 是否离职（0/1，**标签列**）|

```java
DataFrame raw = DataFrame.readCsv("attrition.csv", ",", true);

// ========== ① 探索 ==========
System.out.printf("原始形状: %d 行 × %d 列%n",
    raw.getRowCount(), raw.getColumnCount());
// 输出：原始形状: 1000 行 × 10 列

List<String> colNames = raw.getColumnNames();
List<ColumnType> colTypes = raw.getColumnTypes();
for (int i = 0; i < colNames.size(); i++) {
    System.out.printf("  [%d] %-20s %s%n", i, colNames.get(i), colTypes.get(i));
}

// ========== ② 删除无关列 ==========
// 假设第 0 列是员工ID（字符串，无建模价值），用 sliceColumn 排除
DataFrame cleaned = raw.sliceColumn(1, raw.getColumnCount());  // 删第 0 列

// ========== ③ 标签列分离（最后一个问题：把 left 分出来） ==========
int nCols = cleaned.getColumnCount();
DataFrame features = cleaned.slice(null, "0:" + (nCols - 1));  // 特征：前 n-1 列
DataFrame labels   = cleaned.slice(null, String.valueOf(nCols - 1) + ":");  // 标签：最后一列

// ========== ④ 只取数值特征列（用于 IMatrix） ==========
// 先找出所有数值列的索引
List<Integer> numericColIndices = new ArrayList<>();
for (int i = 0; i < features.getColumnCount(); i++) {
    if (features.get(i).getColumnType() == ColumnType.Numeric) {
        numericColIndices.add(i);
    }
}

// 用 sliceColumn 按索引列表选列（sliceColumn 不支持列表，改为逐个构建）
DataFrame numericFeatures = features.sliceColumn(0, 1);  // 先取第一列
for (int i = 1; i < numericColIndices.size(); i++) {
    // 追加第 numericColIndices.get(i) 列 → 依次 addColumn
    Column c = features.get(numericColIndices.get(i));
    Column cCopy = new Column();
    cCopy.setName(c.getName());
    cCopy.setColumnType(c.getColumnType());
    cCopy.setData(new ArrayList<>(c.getData()));
    numericFeatures.addColumn(cCopy);
}

// ========== ⑤ 转 IMatrix ==========
IMatrix X = numericFeatures.toMatrix();  // [1000, 8] — 8 个数值特征
var y = labels.get(0).toVec();  // 标签向量

System.out.printf("特征矩阵: %d × %d, 标签向量: %d%n",
    X.getRowNum(), X.getColNum(), y.length());
```

## 2.5.3 类别特征编码（One-Hot）

字符串列（如 `department`、`salary`）不能直接喂给线性模型或神经网络，需转为数值。最常用：**One-Hot 编码**——YiShape-Math 本身不提供 One-Hot 工具，但结合 `IMatrix` 可以手动实现：

```java
// 假设 salary 列是 low/medium/high
Column salaryCol = df.getColumnByName("salary");
List<String> uniqueVals = salaryCol.toStringList().stream().distinct().toList();
// uniqueVals = ["low", "medium", "high"]

// 构建 One-Hot 矩阵：每一行 → [1 if low else 0, 1 if medium else 0, 1 if high else 0]
int nRows = df.rows();
int nCats = uniqueVals.size();
double[][] oneHotData = new double[nRows][nCats];

List<String> salaryStrings = salaryCol.toStringList();  // 取一次，避免循环里重复构造
for (int i = 0; i < nRows; i++) {
    String val = salaryStrings.get(i);
    int idx = uniqueVals.indexOf(val);
    if (idx >= 0) oneHotData[i][idx] = 1.0;
}

IMatrix<Double> oneHot = Linalg.matrix(oneHotData);  // [1000, 3]

// 拼接回原有数值特征矩阵（hstack 要求行数一致）
IMatrix<Double> Xaug = X.hstack(oneHot);
System.out.printf("拼接后特征矩阵: %d × %d%n", Xaug.rows(), Xaug.cols());
```

> **说明**：`IMatrix.hstack(other)` 把两个**行数相同**的矩阵左右拼接，等价于 numpy 的 `np.hstack([X, oneHot])`；想纵向叠加用 `vstack`。

## 2.5.4 缺失值处理

YiShape-Math 的 DataFrame 提供了三种缺失值清洗 API；缺失值统一用 `Double.NaN` 或 `null` 表示。

```java
DataFrame df = DataFrame.readCsv("housing.csv");

System.out.println("缺失值总数: " + df.missingCount());
System.out.println("是否含缺失: " + df.hasMissingValues());

// 策略 1：删除任何含缺失的行
DataFrame dropped = df.dropNa();

// 策略 2：用固定值填充（适合稀疏特征/计数特征）
DataFrame zeroed = df.fillNa(0.0);

// 策略 3：用每列均值填充（最常见的数值列处理）
DataFrame imputed = df.fillNaWithMean();

System.out.printf("原始 %d 行 → dropNa 后 %d 行 → fillNa 后 %d 行%n",
    df.rows(), dropped.rows(), imputed.rows());
```

> ⚠️ **`fillNa` 不会就地修改**：和切片一样，三个方法都返回**新的 DataFrame**。原始数据保持不动。
>
> ⚠️ **`fillNaWithMean` 只填数值列**：字符串列里的 `null` 不会被处理；想统一处理字符串缺失需自己遍历。

**按列做不同的填充策略**：库内没有 `fillNa(map)` 这样的列级 API，需要手动按列处理：

```java
DataFrame df = DataFrame.readCsv("housing.csv");

// age 列用均值，household_size 用 0
Column ageCol = df.getColumnByName("age");
double meanAge = ageCol.toVec().mean();
List<Object> ageFilled = new ArrayList<>();
for (Object v : ageCol.getData()) {
    if (v == null || (v instanceof Double d && Double.isNaN(d))) {
        ageFilled.add(meanAge);
    } else {
        ageFilled.add(v);
    }
}
ageCol.setData(ageFilled);
// household_size 列：用 0 填充
Column houseCol = df.getColumnByName("household_size");
List<Object> houseFilled = new ArrayList<>();
for (Object v : houseCol.getData()) {
    if (v == null || (v instanceof Double d && Double.isNaN(d))) {
        houseFilled.add(0.0);
    } else {
        houseFilled.add(v);
    }
}
houseCol.setData(houseFilled);
```

## 2.5.5 与第 5 章的衔接

预处理完成的 `IMatrix X` 和 `IVector y` 直接作为第 5 章机器学习流水线的输入：

```java
import com.yishape.lab.math.ml.ML;
import com.yishape.lab.math.ml.classify.IClassifier;

// 用 X（特征矩阵）和标签训练逻辑回归（label 列已 toVec）
IClassifier clf = ML.clf.logisticRegression(0.01, 0.1);  // l1Weight, l2Weight
clf.fit(X, y);                                            // fit(IMatrix, IVector)

// 评估时用 score / predict 等接口（具体签名见第 5 章）
System.out.printf("训练准确率: %.4f%n", clf.score(X, y));
```

> ⚠️ `ML.logisticRegression(...)` 这种顶层入口**不存在**——分类器都挂在 `ML.clf` 子工厂下；其它常见入口还有 `ML.reg`（回归）、`ML.clu`（聚类）、`ML.dr`（降维）、`ML.dml`（度量学习）、`ML.preproc`（预处理）。

## 本节小结

数据预处理的标准流水线：**加载 → 探索 → 选列 → 缺失值清洗 → One-Hot 编码 → 转矩阵 → 标准化 → 喂给模型**。每一步都有明确的 API 对应：选列用 `selectByName/selectByType/selectColumns`，缺失值用 `dropNa/fillNa/fillNaWithMean`，类别编码需自己写，标准化用 `df.standardize()` / `df.normalize()`。

**核心要点**：YiShape-Math 的 DataFrame 不提供 `groupBy/melt/pivot/Pipeline` 等"大而全"的 pandas 接口；预处理流水线由你自己用现有 API 串起来。

## 本节 API 一览

| 场景            | API                                            | 说明                                                |
| ------------- | ---------------------------------------------- | ------------------------------------------------- |
| 缺失值检测         | `df.hasMissingValues()` / `df.missingCount()`  | 整体判断；列级用 `col.hasMissingValues()` / `validCount()` |
| 删除缺失行         | `df.dropNa()`                                  | 返回新 DataFrame                                     |
| 固定值填充         | `df.fillNa(double value)`                      | 仅作用于数值列                                            |
| 列均值填充         | `df.fillNaWithMean()`                          | 仅作用于数值列                                            |
| 按类型筛列         | `df.selectByType(ColumnType)`                  | 例如只保留 `ColumnType.Numeric`                        |
| 只取数值列         | `df.selectNumeric()`                           | `selectByType(Numeric)` 的快捷形式                     |
| 按名称筛列         | `df.selectByName(regex)` / `excludeByName(regex)` | 正则匹配                                              |
| 按名称列表选列       | `df.selectColumns(List<String>)`               | 显式指定列名顺序                                            |
| 标准化（z-score） | `df.standardize()`                             | 仅作用于数值列；新 DataFrame                                |
| Min-Max 归一化   | `df.normalize()`                               | 同上，范围归一到 `[0, 1]`                                  |
| 训练/测试集分割     | `df.trainTestSplit(double ratio)`              | 返回 `DataFrame[2]`                                 |
| 洗牌            | `df.shuffle(long seed)`                        | 固定种子                                              |
| 拼接 / 横向       | `IMatrix.hstack(other)` / `vstack(other)`       | 用于 One-Hot 拼接                                     |

> ⚠️ **不存在的 API**：`Pipeline.of(...)`、`pipeline.fit/transform/fitTransform`、`DataFrame.oneHot(...)`、`df.fillNull("mean")`、`ML.trainTestSplit(X, y, ratio)`、`pipeline.save(path)` 等"流水线对象"接口本库目前都不提供。如果你想要可序列化的端到端流水线，可以自己写一个把现有 API 组合起来的 Builder。

**1. 完整Pipeline构建（实操题）**

用Pipeline构建以下流水线：缺失值均值填充 → 标准化 → PCA降维 → 线性回归。
