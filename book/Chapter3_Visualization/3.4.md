# 3.4 YiShape-Math集成应用 / YiShape-Math Integration Applications

## 3.4.1 数学计算与可视化的无缝衔接


> 📝 **历史故事**：Seaborn 由 **Michael Waskom（2012）** 在 Stanford 神经科学实验室创建——他需要快速画出好看的统计图，Matplotlib 太底层，于是写了 seaborn。GitHub Stars 超过 10k，成为 Python 可视化的标配。

> **📌 学习目标**
> - 理解笛卡尔坐标 vs 极坐标的适用场景（周期性数据）
> - 掌握直方图、箱线图、小提琴图的适用场景
> - 能用极坐标绘制饼图、雷达图、玫瑰图

写机器学习代码时，你是否经历过这样的折腾——先用 `RereLinearRegression` 算出模型系数，再把数据导到 Python 用 **Matplotlib**（Python 可视化库）画损失曲线？在 YiShape-Math 中，`IVector` / `IMatrix` 的计算结果**直接流入** `Plots`，几行代码就能把抽象的数值变成看得见的图形。

这种「计算→可视化」一体化有三重好处：
- **零拷贝**：内部共享数据视图，无需复制就能直接画图
- **链式编程**：`Plots.of(...).line(data).boxplot(data).saveAsHtml(...)` 一气呵成，代码干净
- **类型安全**：`IVector` → `Plots` 的数据流在编译时就检查，不必等到运行时才发现传错了类型

> **设计思想**：YiShape-Math 的 `com.yishape.lab.math.plot` 模块采用**门面模式**（Facade），`Plots` 是统一入口，底层根据当前 `PlotProvider`（JavaFx / Echarts / Svg）自动选择渲染后端——用户只管「画什么」，不必操心「怎么画」。

## 3.4.2 线性代数计算可视化

### 线性代数计算可视化

```java
import com.yishape.lab.math.linalg.IMatrix;
import com.yishape.lab.math.linalg.IVector;
import com.yishape.lab.math.linalg.Linalg;
import com.yishape.lab.math.plot.Plots;
import com.yishape.lab.util.Tuple2;
import java.util.Arrays;

public class LinearAlgebraVisualizationExample {
    public static void main(String[] args) {
        // 矩阵运算结果可视化
        IMatrix<Double> matrixA = Linalg.matrix(new double[][]{
                {1, 2, 3},
                {4, 5, 6},
                {7, 8, 9}
        });

        IMatrix<Double> matrixB = Linalg.matrix(new double[][]{
                {9, 8, 7},
                {6, 5, 4},
                {3, 2, 1}
        });

        // 矩阵加法
        IMatrix<Double> sumMatrix = matrixA.add(matrixB);

        // 可视化矩阵加法结果 - 使用流式API
        Plots.of(800, 600)
                .heatmap(sumMatrix,
                        Arrays.asList("列1", "列2", "列3"),
                        Arrays.asList("行1", "行2", "行3"))
                .title("矩阵加法结果", "A + B 的可视化展示")
                .saveAsHtml("matrix_addition_heatmap.html");

        // 特征值计算与可视化（需用 eigen() 取特征值向量）
        Tuple2<IVector<Double>, IMatrix<Double>> eig = matrixA.eigen();
        IVector<Double> eigenvalues = eig._1;       // 第一个分量为特征值向量
        Plots.of(800, 600)
                .bar(eigenvalues)
                .title("矩阵特征值", "特征值分布情况")
                .xlabel("特征值索引")
                .ylabel("特征值大小")
                .saveAsHtml("eigenvalues_bar_chart.html");
    }
}
```

### 统计分析可视化

```java
public class StatisticalAnalysisVisualizationExample {
    public static void main(String[] args) {
        // 生成随机数据
        IVector<Double> data = generateRandomData(1000);

        // 计算统计量（IVector 的 mean/std/median 均返回 double，不是 float）

        // 创建统计摘要可视化 - 使用流式API

            .hist(data, true) // 第二参数为是否叠加拟合曲线（boolean）

                String.format("均值: %.2f, 标准差: %.2f, 中位数: %.2f", mean, std, median))
            .xlabel("数值")
            .ylabel("频次")
            .saveAsHtml("statistical_analysis.html");

        // 箱线图分析 - 使用流式API
        Plots.of(800, 600)
            .boxplot(data)
            .title("数据分布箱线图", "统计特征分析")
            .xlabel("数据集")
            .ylabel("数值")
            .saveAsHtml("boxplot_analysis.html");
    }

    private static IVector<Double> generateRandomData(int size) {
        double[] data = new double[size];
        for (int i = 0; i < size; i++) {
            data[i] = Math.random() * 10 + 5; // 均值 5，标准差约 2.9
        }
        return Linalg.vector(data);
    }
}
```

## 3.4.3 机器学习模型可视化 / Machine Learning Model Visualization

### 模型训练过程可视化

```java
public class MLModelVisualizationExample {
    public static void main(String[] args) {
        // 线性回归模型训练可视化（带 1 截距列的设计矩阵 X）
        IMatrix<Double> X = Linalg.matrix(new double[][]{
            {1, 1}, {1, 2}, {1, 3}, {1, 4}, {1, 5}
        });
        IVector<Double> y = Linalg.vector(new double[]{2, 4, 6, 8, 10});

        // 训练过程记录
        List<Double> epochs = new ArrayList<>();
        List<Double> losses = new ArrayList<>();

        // 模拟训练过程：手写 SGD，用 mmul 做矩阵-向量乘法（multiply 是 Hadamard 元素积）
        double[] weights = {0.0, 0.0};
        double lr = 0.01;
        for (int epoch = 0; epoch < 50; epoch++) {
            IVector<Double> predictions = X.mmul(Linalg.vector(weights));
            IVector<Double> errors = predictions.subtract(y);

            double loss = errors.dot(errors) / (2.0 * y.length());
            losses.add(loss);
            epochs.add((double) epoch);

            // 梯度 g = (1/n) Xᵀ e；用 mmul 而不是 multiply
            IVector<Double> gradients = X.transpose().mmul(errors).multiply(1.0 / y.length());
            for (int i = 0; i < weights.length; i++) {
                weights[i] -= lr * gradients.get(i);
            }
        }

        // 训练损失曲线 - 使用流式API
        Plots.of(800, 600)
            .line(Linalg.vector(epochs.stream().mapToDouble(Double::doubleValue).toArray()),
                  Linalg.vector(losses.stream().mapToDouble(Double::doubleValue).toArray()))
            .title("模型训练损失", "损失函数随训练轮次的变化")
            .xlabel("训练轮次")
            .ylabel("损失值")
            .saveAsHtml("training_loss.html");
    }
}
```

## 3.4.5 金融数据分析可视化 / Financial Data Analysis Visualization

### 投资组合分析

```java
public class PortfolioAnalysisVisualizationExample {
    public static void main(String[] args) {
        // 模拟股票价格数据
        int days = 252; // 一年的交易日
        IVector<Double> dates = generateTradingDates(days);

        // 三只股票的价格数据
        IVector<Double> stock1 = generateStockPrices(100.0, 0.0008, 0.015, days);
        IVector<Double> stock2 = generateStockPrices(50.0,  0.0004, 0.012, days);
        IVector<Double> stock3 = generateStockPrices(75.0,  0.0006, 0.018, days);

        // 股票价格走势 - 使用流式API（三条线同图叠加）
        Plots.of(1000, 600)
            .line(dates, stock1)
            .line(dates, stock2)
            .line(dates, stock3)
            .title("股票价格走势", "三只股票的价格变化")
            .xlabel("日期")
            .ylabel("价格 ($)")
            .saveAsHtml("stock_prices.html");
    }

    private static IVector<Double> generateTradingDates(int days) {
        double[] dates = new double[days];
        for (int i = 0; i < days; i++) {
            dates[i] = i;
        }
        return Linalg.vector(dates);
    }

    private static IVector<Double> generateStockPrices(double initialPrice, double drift, double volatility, int days) {
        double[] prices = new double[days];
        prices[0] = initialPrice;
        for (int i = 1; i < days; i++) {
            double randomShock = (Math.random() - 0.5) * volatility;
            prices[i] = prices[i - 1] * (1 + drift + randomShock);
        }
        return Linalg.vector(prices);
    }
}
```

### 流式数据处理可视化

```java
public class RealTimeVisualizationExample {
    public static void main(String[] args) {
        // 模拟实时数据流：用 double[] 直接累积，避免 List<Float> 装箱
        int n = 100;
        double[] timePoints = new double[n];
        double[] dataValues = new double[n];

        for (int i = 0; i < n; i++) {
            timePoints[i] = i;
            dataValues[i] = Math.sin(i * 0.1) + Math.random() * 0.5;
        }

        // 实时数据趋势图 - 使用流式API
        Plots.of(1000, 600)
            .line(Linalg.vector(timePoints), Linalg.vector(dataValues))
            .title("实时数据监控", "数据流实时变化趋势")
            .xlabel("时间")
            .ylabel("数值")
            .saveAsHtml("realtime_data.html");
    }
}
```

> 📝 **关于实时刷新**：`Plots` 当前侧重「批量出图 → 静态/交互式 HTML」工作流，并不提供内置的流式重绘 API。若需要「窗口滚动」效果，可在外层维护一个滚动缓冲区（如长度 N 的环形 buffer），每隔固定时间用最新数据重新调用 `Plots.of(...).line(...).saveAsHtml(...)` 覆盖文件即可。

## 3.4.7 集成应用最佳实践 / Integration Application Best Practices

### 性能优化策略

```java
public class PerformanceOptimizationExample {
    public static void main(String[] args) {
        // 大数据集处理优化
        int dataSize = 100000;
        IVector<Double> largeDataset = generateLargeDataset(dataSize);
        
        // 数据采样策略
        if (largeDataset.length() > 10000) {
            IVector<Double> sampledData = downsampleEvenly(largeDataset, 10_000);
            System.out.println("大数据集采样处理，从 " + dataSize + " 个点采样到 " + sampledData.length() + " 个点");
        }
        
        // 内存优化：使用流式处理
        processDataInChunks(largeDataset, 1000);
    }
    
    private static IVector<Double> generateLargeDataset(int size) {
        double[] data = new double[size];
        for (int i = 0; i < size; i++) {
            data[i] = Math.random() * 100;
        }
        return Linalg.vector(data);
    }

    /** 等间隔抽样:从长度 n 的向量等步长选出 k 个元素。 */
    private static IVector<Double> downsampleEvenly(IVector<Double> data, int k) {
        int n = data.length();
        double[] out = new double[k];
        for (int i = 0; i < k; i++) {
            int idx = (int) ((long) i * (n - 1) / Math.max(1, k - 1));
            out[i] = data.get(idx);
        }
        return Linalg.vector(out);
    }

    private static void processDataInChunks(IVector<Double> data, int chunkSize) {
        for (int i = 0; i < data.length(); i += chunkSize) {
            int end = Math.min(i + chunkSize, data.length());
            IVector<Double> chunk = data.slice(i, end);
            processChunk(chunk);
        }
    }
```

> ⚠️ **常见陷阱**:`Plots` 的 builder 调用是**有副作用的**(每次 `.line(...)` 都把新系列加入当前 plot)。如果在循环中复用同一个 `IPlot` 实例,会得到「累加多条线」的图——这通常正是想要的,但当你想要「每轮一张图」时务必每轮重新 `Plots.of(...)` 创建新实例。

## 本节小结

YiShape-Math 的 `com.yishape.lab.math.plot` 模块以 `Plots`(2D)/`Plots3d`(3D) 为静态门面,以 `IPlot`(2D) / `I3dPlot`(3D) 为流式 API 入口,后端通过 `PlotProvider` 选择 ECharts / JavaFx / SVG。配合 `IVector` / `IMatrix` 的零拷贝传入,可以做到「算出来就能画出来」。

**核心要点**:
1. **门面 + 流式**:`Plots.of(w, h).<chart>(data).title(...).saveAsXxx(file)` 一行完成。
2. **类型对齐**:图表方法接受 `IVector<?>` / `IMatrix<?>`,直接由 `Linalg.vector(...)` / `Linalg.matrix(...)` 构造,避免装箱。
3. **后端透明**:Echarts 导出 HTML(交互式);SVG 适合论文出版;JavaFx 适合桌面应用。

## 本节 API 一览(本节实际用到的 API)

| 场景 | API | 必填参数与返回 |
|------|-----|----------------|
| 矩阵热力图 | `Plots.of(w,h).heatmap(matrix, xLabels, yLabels)` | matrix:`IMatrix<?>`;两组标签长度需与行列数一致 |
| 特征值柱状图 | `Plots.of(w,h).bar(eigenvalues)` | `IVector<?>`,与 `IMatrix#eigen()._1` 直接对接 |
| 直方图 | `Plots.of(w,h).hist(data, true)` | `(IVector<?>, boolean fittingLine)`(注意 boolean,**不是** bin 数) |
| 箱线图 | `Plots.of(w,h).boxplot(data)` | `IVector<?>`;多组用 `.boxplot(data, labels)` |
| 训练曲线 | `Plots.of(w,h).line(x, y)` | 两个 `IVector<?>`,等长 |
| 多线叠加 | 连续调用 `.line(x, y1).line(x, y2)...` | 同一 `IPlot` 上叠加多条曲线 |
| 保存 | `.saveAsHtml(file)` / `.saveAsSvg(file)` / `.saveAsPng(file)` / `.saveAsPdf(file)` | 通用 `.save(...)` 方法**不存在** |

> ⚠️ **不存在的 API**:
> - `Plots.heatmap(matrix, "viridis")` 单字符串调色板重载——颜色控制走 `PlotStyle` 参数,不是字符串名。
> - `Plots.surface(x, y, z)`——3D 曲面在 `I3dPlot` 上,需先通过 `Plots.of3d(w, h).surface3d(x, y, zMatrix)` 进入 3D 子树,且 z 是 `IMatrix`(网格),不是向量。
> - `Plots.scatter(...).addLine()`——`IPlot` 没有 `addLine`;若要在散点上叠回归线,继续链式调用 `.line(x, yFit)` 即可。
> - `Plots.hist(data, nBins)`——`hist` 的第二参数是 `boolean fittingLine`。要指定分箱数请用 `.hist(data, true, (PlotStyle) null, 30)` 这一 4 参重载。
> - `IVector#sample(int)`——没有内置随机抽样,需要自己用 `Random` + `slice`/`get` 实现。
