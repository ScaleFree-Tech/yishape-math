# 3.4 YiShape-Math集成应用 / YiShape-Math Integration Applications

## 3.4.1 数学计算与可视化的无缝衔接


> 📝 **历史故事**：Seaborn 由 **Michael Waskom（2012）** 在 Stanford 神经科学实验室创建——他需要快速画出好看的统计图，Matplotlib 太底层，于是写了 seaborn。GitHub Stars 超过 10k，成为 Python 可视化的标配。

> **📌 学习目标**
> - 理解笛卡尔坐标 vs 极坐标的适用场景（周期性数据）
> - 掌握直方图、箱线图、小提琴图的适用场景
> - 能用极坐标绘制饼图、雷达图、玫瑰图

写机器学习代码时，你是否经历过这样的折腾——先用 `RereLinearRegression` 算出模型系数，再把数据导到 Python 用 **Matplotlib**（Python 可视化库）画损失曲线？在 YiShape-Math 中，`IVector` / `IMatrix` 的计算结果**直接流入** `Plots`，几行代码就能把抽象的数值变成看得见的图形。

这种「计算→可视化」一体化有三重好处：
- **零拷贝**：内部共享数据视图，无需复制就能直接画图
- **链式编程**：`Plots.of(...).line(data).boxplot(data).saveAsHtml(...)` 一气呵成，代码干净
- **类型安全**：`IVector` → `Plots` 的数据流在编译时就检查，不必等到运行时才发现传错了类型

> **设计思想**：YiShape-Math 的 `viz` 模块采用**门面模式**（Facade），`Plots` 是统一入口，底层自动选择 ECharts 的合适图表类型——用户只管「画什么」，不必操心「怎么画」。

## 3.4.2 线性代数计算可视化

### 线性代数计算可视化

```java
import com.yishape.lab.math.linalg.IMatrix;
import com.yishape.lab.math.linalg.IVector;
import com.yishape.lab.math.linalg.Linalg;
import com.yishape.lab.math.viz.Plots;
import com.yishape.lab.util.Tuple2;

public class LinearAlgebraVisualizationExample {
    public static void main(String[] args) {
        // 矩阵运算结果可视化
        IMatrix matrixA = Linalg.matrix(new double[][]{
                {1, 2, 3},
                {4, 5, 6},
                {7, 8, 9}
        });

        IMatrix matrixB = Linalg.matrix(new double[][]{
                {9, 8, 7},
                {6, 5, 4},
                {3, 2, 1}
        });

        // 矩阵加法
        IMatrix sumMatrix = matrixA.add(matrixB);

        // 可视化矩阵加法结果 - 使用流式API
        Plots.of(800, 600)
                .heatmap(sumMatrix,
                        Arrays.asList("列1", "列2", "列3"),
                        Arrays.asList("行1", "行2", "行3"))
                .title("矩阵加法结果", "A + B 的可视化展示")
                .saveAsHtml("matrix_addition_heatmap.html");

        // 特征值计算与可视化（需用 eigen() 取特征值向量）
        Tuple2<IVector<Double>, IMatrix<Double>> eig = matrixA.eigen();
        var eigenvalues = eig._1;  // 第一个分量为特征值向量
        Plots.of(800, 600)
                .bar(eigenvalues)
                .title("矩阵特征值", "特征值分布情况")
                .xlabel("特征值索引")
                .ylabel("特征值大小")
                .saveAsHtml("eigenvalues_bar_chart.html");
    }
}
```

## 3.4.3 机器学习模型可视化 / Machine Learning Model Visualization

### 模型训练过程可视化

```java
public class MLModelVisualizationExample {
    public static void main(String[] args) {
        // 线性回归模型训练可视化
        IMatrix X = Linalg.matrix(new double[][]{
            {1, 1}, {1, 2}, {1, 3}, {1, 4}, {1, 5}
        });
        IVector y = Linalg.vector(new double[]{2, 4, 6, 8, 10});
        
        // 训练过程记录
        List<Float> epochs = new ArrayList<>();
        List<Float> losses = new ArrayList<>();
        
        // 模拟训练过程
        float[] weights = {0.0f, 0.0f};
        for (int epoch = 0; epoch < 50; epoch++) {
            // 前向传播
            IVector predictions = X.multiply(Linalg.vector(weights));
            IVector errors = predictions.subtract(y);
            
            // 计算损失
            float loss = errors.dot(errors) / (2 * y.length());
            losses.add(loss);
            epochs.add((float) epoch);
            
            // 更新权重
            IVector gradients = X.transpose().multiply(errors).divide(y.length());
            for (int i = 0; i < weights.length; i++) {
                weights[i] -= 0.01 * gradients.get(i);
            }
        }
        
        // 训练损失曲线 - 使用流式API
        Plots.of(800, 600)
            .line(Linalg.vector(epochs), Linalg.vector(losses))
            .title("模型训练损失", "损失函数随训练轮次的变化")
            .xlabel("训练轮次")
            .ylabel("损失值")
            .saveAsHtml("training_loss.html");
    }
}
```

## 3.4.5 金融数据分析可视化 / Financial Data Analysis Visualization

### 投资组合分析

```java
public class PortfolioAnalysisVisualizationExample {
    public static void main(String[] args) {
        // 模拟股票价格数据
        int days = 252; // 一年的交易日
        IVector dates = generateTradingDates(days);
        
        // 三只股票的价格数据
        IVector stock1 = generateStockPrices(100.0f, 0.02f, 0.15f, days);
        IVector stock2 = generateStockPrices(50.0f, 0.01f, 0.12f, days);
        IVector stock3 = generateStockPrices(75.0f, 0.015f, 0.18f, days);
        
        // 股票价格走势 - 使用流式API
        Plots.of(1000, 600)
            .line(dates, stock1)
            .line(dates, stock2)
            .line(dates, stock3)
            .title("股票价格走势", "三只股票的价格变化")
            .xlabel("日期")
            .ylabel("价格 ($)")
            .saveAsHtml("stock_prices.html");
    }
    
    private static IVector generateTradingDates(int days) {
        float[] dates = new float[days];
        for (int i = 0; i < days; i++) {
            dates[i] = i;
        }
        return Linalg.vector(dates);
    }
    
    private static IVector generateStockPrices(float initialPrice, float drift, float volatility, int days) {
        float[] prices = new float[days];
        prices[0] = initialPrice;
        
        for (int i = 1; i < days; i++) {
            float randomShock = (float) (Math.random() - 0.5) * volatility;
            prices[i] = prices[i-1] * (1 + drift + randomShock);
        }
        
        return Linalg.vector(prices);
    }
}
```

## 本节小结

YiPlot 基于 HTML5 Canvas，支持散点图、折线图、柱状图、热力图等。Python 用户可用 matplotlib/seaborn 生成高质量图表，导出为 PNG 后嵌入文档。

**核心要点**：Python 可视化生态成熟（matplotlib/seaborn/plotly）；Java 可视化可借助 YiPlot 或 JFreeChart；图表应先追求准确，再追求美观。

## 本节 API 一览

| 场景 | API | 说明 |
|------|-----|------|
| 矩阵可视化 | `Plots.heatmap(matrix, "viridis")` | 热力图颜色映射 |
| 特征值谱 | `Plots.surface(x, y, z)` | 3D曲面图 |
| 残差诊断 | `Plots.scatter(yTrue, yPred).addLine()` | 回归残差图 |
| 收敛曲线 | `Plots.line(steps, losses)` | 优化过程可视化 |
| 特征分布 | `Plots.hist(features, nBins)` | 特征直方图矩阵 |

> **用法**：在Jupyter/IDE中直接调用，自动渲染，无需手动管理canvas。
