# 3.5 实际应用案例

## 开场：技术分析的真正价值——不是预测，而是纪律


> **📌 学习目标**
> - 掌握调色板选择：定性（分类）/ 定量（渐变）/ 顺序（单向）
> - 能用 `theme()` 自定义字体、背景、网格线
> - 理解色盲友好配色的重要性

做股票技术分析的人，最常犯的错误是：把图表当成「预测未来的水晶球」。

实际上，技术分析的价值不在预测，而在**纪律**：

- 移动平均线告诉你在趋势反转时「什么时候该走」——而不是「明天涨还是跌」
- RSI（相对强弱指数）告诉你市场是不是已经「过热」——而不是告诉你具体价格
- 布林带告诉你价格现在有多「极端」——在统计学意义上，这是有价值的信号

本节用两个完整的案例，展示**YiShape-Math 如何串联数据计算和可视化**：
1. 股票技术分析系统——从价格数据到均线、RSI、成交量全套
2. 投资组合风险管理——从历史收益到波动率、VaR

### 案例1：数值模拟可视化

```java
public class NumericalSimulationVisualization {
    public static void main(String[] args) {
        // 热传导方程数值解
        IMatrix temperatureField = solveHeatEquation(100, 100, 1000);
        
        // 创建模拟结果可视化
        createSimulationVisualization(temperatureField);
    }
    
    private static IMatrix solveHeatEquation(int nx, int ny, int timeSteps) {
        // 简化的热传导方程求解
        IMatrix u = IMatrix.zeros(nx, ny);
        
        // 初始条件
        for (int i = 0; i < nx; i++) {
            for (int j = 0; j < ny; j++) {
                if (i == nx/2 && j == ny/2) {
                    u.set(i, j, 100.0f); // 热源
                }
            }
        }
        
        // 时间步进
        float dt = 0.01f;
        float dx = 1.0f / nx;
        float dy = 1.0f / ny;
        
        for (int t = 0; t < timeSteps; t++) {
            IMatrix uNew = u.copy();
            for (int i = 1; i < nx-1; i++) {
                for (int j = 1; j < ny-1; j++) {
                    float d2udx2 = (u.get(i+1, j) - 2*u.get(i, j) + u.get(i-1, j)) / (dx*dx);
                    float d2udy2 = (u.get(i, j+1) - 2*u.get(i, j) + u.get(i, j-1)) / (dy*dy);
                    uNew.set(i, j, u.get(i, j) + dt * (d2udx2 + d2udy2));
                }
            }
            u = uNew;
        }
        
        return u;
    }
    
    private static void createSimulationVisualization(IMatrix temperatureField) {
        // 温度场热力图
        IPlot heatmap = Plots.of(800, 600);
        List<String> xLabels = generateLabels(temperatureField.getCols());
        List<String> yLabels = generateLabels(temperatureField.getRows());
        heatmap.heatmap(temperatureField, xLabels, yLabels);
        heatmap.setTitle("热传导数值模拟", "温度场分布");
        heatmap.saveAsHtml("heat_conduction_simulation.html");
        
        // 温度剖面图
        IVector centerRow = temperatureField.getRow(temperatureField.getRows()/2);
        IVector xPositions = IVector.linspace(0, 1, centerRow.length());
        IPlot profilePlot = Plots.of(800, 600);
        profilePlot.line(xPositions, centerRow);
        profilePlot.setTitle("温度剖面图", "中心线温度分布");
        profilePlot.setXlabel("位置");
        profilePlot.setYlabel("温度");
        profilePlot.saveAsHtml("temperature_profile.html");
    }
}
```

### 案例2：信号处理分析

```java
public class SignalProcessingAnalysis {
    public static void main(String[] args) {
        // 生成复合信号
        IVector time = IVector.linspace(0, 1, 1000);
        IVector signal = generateCompositeSignal(time);
        
        // 信号分析
        IVector fft = calculateFFT(signal);
        IVector frequencies = IVector.linspace(0, 500, fft.length());
        
        // 创建信号分析可视化
        createSignalAnalysisVisualization(time, signal, frequencies, fft);
    }
    
    private static IVector generateCompositeSignal(IVector time) {
        return time.map(t -> 
            (float) (Math.sin(2 * Math.PI * 10 * t) + 
                    0.5 * Math.sin(2 * Math.PI * 25 * t) + 
                    0.3 * Math.sin(2 * Math.PI * 50 * t) +
                    0.1 * Math.random())
        );
    }
    
    private static void createSignalAnalysisVisualization(IVector time, IVector signal, 
                                                         IVector frequencies, IVector fft) {
        // 时域信号
        IPlot timeDomain = Plots.of(800, 400);
        timeDomain.line(time, signal);
        timeDomain.setTitle("时域信号", "原始信号波形");
        timeDomain.setXlabel("时间 (s)");
        timeDomain.setYlabel("幅度");
        timeDomain.saveAsHtml("time_domain_signal.html");
        
        // 频域分析
        IPlot freqDomain = Plots.of(800, 400);
        freqDomain.line(frequencies, fft);
        freqDomain.setTitle("频域分析", "信号频谱");
        freqDomain.setXlabel("频率 (Hz)");
        freqDomain.setYlabel("幅度");
        freqDomain.saveAsHtml("frequency_domain_analysis.html");
        
        // 时频分析（简化）
        IMatrix spectrogram = calculateSpectrogram(signal, 64);
        IPlot spectrogramPlot = Plots.of(800, 400);
        List<String> timeLabels = generateLabels(spectrogram.getCols());

        spectrogramPlot.saveAsHtml("spectrogram_analysis.html");
    }
}
```

## 3.5.7 案例总结与最佳实践 / Case Summary and Best Practices

#（参考第 7 章时序分析中的热力图：时间 × 类别的二维分解是时序可视化的重要工具。）
## 案例设计原则

**数据驱动** / **Data-Driven**:
- 以实际数据为基础进行可视化设计
- 确保数据的准确性和完整性
- 考虑数据的时效性和更新频率

**用户导向** / **User-Oriented**:
- 根据目标用户群体设计可视化方案
- 提供直观易懂的图表展示
- 支持交互式探索和分析

**业务价值** / **Business Value**:
- 可视化结果能够支持业务决策
- 提供可操作的洞察和建议
- 建立持续改进的反馈机制

### 技术实现要点 / Technical Implementation Points

**性能优化** / **Performance Optimization**:
- 合理选择图表类型和复杂度
- 实施数据采样和聚合策略
- 优化渲染性能和内存使用

**可维护性** / **Maintainability**:
- 采用模块化的代码结构
- 提供清晰的配置和参数设置
- 建立完善的错误处理机制

**扩展性** / **Scalability**:
- 设计灵活的图表配置系统
- 支持多种数据源和格式
- 提供插件化的扩展机制

## 本节小结

热力图用颜色深浅表示数值大小，适合展示矩阵格式的相关性或用户行为。相关系数矩阵热力图是特征选择的重要工具。

**核心要点**：热力图适合高维数据的全局概览；相关系数热力图揭示特征间的线性关系；颜色映射要选对色盲友好的调色板。

## 本节 API 一览

| 场景 | API | 说明 |
|------|-----|------|
| 动态更新 | `Plots.of(w,h).update(data)` | 数据流实时刷新 |
| 多图表联动 | `Plots.link(chart1, chart2)` | 同步缩放/框选 |
| 子图布局 | `Plots.subplot(nRows, nCols)` | 多图网格 |
| 仪表盘导出 | `Plots.exportDashboard(plots, path)` | HTML仪表盘 |
| 动画录制 | `Plots.recordAnimation(frames)` | 保存为MP4/GIF |

> **仪表盘最佳实践**：左侧放控制参数图表，右侧放结果图表，点击联动刷新。
