## 3.6.1

> 📝 **历史故事**：数据可视化的革命来自 **Edward Tufte（1983）** 的《The Visual Display of Quantitative Information》。他的核心原则「数据-墨水比」和「Chartjunk（图表垃圾）」彻底改变了人们对图表的认知。Tufte 本人是耶鲁大学的政治学和统计学教授，他把自己在越战期间做数据分析的经验写成书，意外成为可视化设计的圣经。

## 3.6.2 性能优化策略 / Performance Optimization Strategies

### 数据处理优化 / Data Processing Optimization

#### 大数据集处理 / Large Dataset Processing

**数据采样** / **Data Sampling**:
- **随机采样** / **Random Sampling**: 对大数据集进行随机采样
- **分层采样** / **Stratified Sampling**: 保持数据分布特征的采样
- **时间窗口采样** / **Time Window Sampling**: 按时间窗口进行采样
- **自适应采样** / **Adaptive Sampling**: 根据数据特征动态调整采样策略

```java
public class DataSamplingExample {
    public static void main(String[] args) {
        // 大数据集采样处理
        IVector largeDataset = generateLargeDataset(1000000);
        
        // 随机采样
        IVector randomSample = largeDataset.sample(10000);
        createVisualization(randomSample, "random_sample");
        
        // 分层采样
        IVector stratifiedSample = stratifiedSampling(largeDataset, 10000);
        createVisualization(stratifiedSample, "stratified_sample");
        
        // 时间窗口采样
        IVector timeWindowSample = timeWindowSampling(largeDataset, 1000);
        createVisualization(timeWindowSample, "time_window_sample");
    }
    
    private static IVector generateLargeDataset(int size) {
        float[] data = new float[size];
        for (int i = 0; i < size; i++) {
            data[i] = (float) (Math.random() * 100);
        }
        return Linalg.vector(data);
    }
    
    private static IVector stratifiedSampling(IVector data, int sampleSize) {
        // 简化的分层采样实现
        var strata = new int[data.length()];
        for (int i = 0; i < data.length(); i++) {
            strata[i] = (int) (data.get(i) / 10); // 按数值范围分层
        }
        
        // 每层按比例采样
        return data.sample(sampleSize);
    }
    
    private static IVector timeWindowSampling(IVector data, int windowSize) {
        // 时间窗口采样
        int step = data.length() / windowSize;
        float[] sampled = new float[windowSize];
        for (int i = 0; i < windowSize; i++) {
            sampled[i] = data.get(i * step);
        }
        return Linalg.vector(sampled);
    }
    
    private static void createVisualization(IVector data, String name) {
        RerePlot plot = Plots.of(800, 600);
        plot.hist(data, true);
        plot.setTitle("数据分布 - " + name, "采样后的数据分布");
        plot.saveAsHtml(name + "_visualization.html");
    }
}
```

#### 内存优化 / Memory Optimization

**内存管理** / **Memory Management**:
- **对象复用** / **Object Reuse**: 复用图表对象减少内存分配
- **数据压缩** / **Data Compression**: 使用压缩算法减少内存占用
- **懒加载** / **Lazy Loading**: 按需加载数据减少初始内存使用
- **垃圾回收优化** / **Garbage Collection Optimization**: 优化对象生命周期

```java
public class MemoryOptimizationExample {
    private static RerePlot plot = Plots.of(800, 600); // 复用图表对象
    
    public static void main(String[] args) {
        // 使用对象池管理图表
        ChartPool chartPool = new ChartPool(10);
        
        for (int i = 0; i < 100; i++) {
            IPlot chart = chartPool.getChart();
            try {
                processData(chart, generateData(i));
            } finally {
                chartPool.returnChart(chart);
            }
        }
    }
    
    private static void processData(IPlot chart, IVector data) {
        chart.line(data);
        chart.setTitle("数据处理结果", "第" + System.currentTimeMillis() + "次处理");
        chart.saveAsHtml("data_" + System.currentTimeMillis() + ".html");
    }
    
    private static IVector generateData(int index) {
        float[] data = new float[1000];
        for (int i = 0; i < 1000; i++) {
            data[i] = (float) Math.sin(i * 0.01 + index) * 100;
        }
        return Linalg.vector(data);
    }
    
    // 图表对象池
    static class ChartPool {
        private final Queue<IPlot> pool;
        private final int maxSize;
        
        public ChartPool(int maxSize) {
            this.maxSize = maxSize;
            this.pool = new LinkedList<>();
        }
        
        public IPlot getChart() {
            IPlot chart = pool.poll();
            if (chart == null) {
                chart = Plots.of(800, 600);
            }
            return chart;
        }
        
        public void returnChart(IPlot chart) {
            if (pool.size() < maxSize) {
                // 重置图表状态
                chart.setTitle("", "");
                pool.offer(chart);
            }
        }
    }
}
```

### 渲染性能优化 / Rendering Performance Optimization

#### 图表渲染优化 / Chart Rendering Optimization

**渲染策略** / **Rendering Strategies**:
- **增量渲染** / **Incremental Rendering**: 只渲染变化的部分
- **异步渲染** / **Asynchronous Rendering**: 使用异步渲染避免阻塞
- **缓存机制** / **Caching Mechanism**: 缓存渲染结果避免重复计算
- **LOD技术** / **Level of Detail**: 根据缩放级别调整细节程度

```java
public class RenderingOptimizationExample {
    public static void main(String[] args) {
        // 异步渲染示例
        createAsyncVisualization();
        
        // 缓存机制示例
        createCachedVisualization();
    }
    
    private static void createAsyncVisualization() {
        // 大数据集异步渲染
        CompletableFuture.supplyAsync(() -> {
            IVector largeData = generateLargeDataset(100000);
            return processLargeDataset(largeData);
        }).thenAccept(result -> {
            RerePlot plot = Plots.of(800, 600);
            plot.line(result);
            plot.setTitle("异步渲染结果", "大数据集异步处理完成");
            plot.saveAsHtml("async_rendering_result.html");
        });
    }
    
    private static void createCachedVisualization() {
        // 使用缓存避免重复计算
        VisualizationCache cache = new VisualizationCache();
        
        String dataKey = "dataset_1";
        IVector data = cache.getOrCompute(dataKey, () -> {
            return generateLargeDataset(50000);
        });
        
        RerePlot plot = Plots.of(800, 600);
        plot.line(data);
        plot.setTitle("缓存渲染结果", "使用缓存避免重复计算");
        plot.saveAsHtml("cached_rendering_result.html");
    }
    
    private static IVector generateLargeDataset(int size) {
        float[] data = new float[size];
        for (int i = 0; i < size; i++) {
            data[i] = (float) Math.random() * 100;
        }
        return Linalg.vector(data);
    }
    
    private static IVector processLargeDataset(IVector data) {
        // 模拟复杂的数据处理
        return data.map(x -> x * x + Math.sin(x));
    }
    
    // 可视化缓存
    static class VisualizationCache {
        private final Map<String, IVector> cache = new ConcurrentHashMap<>();
        
        public IVector getOrCompute(String key, Supplier<IVector> supplier) {
            return cache.computeIfAbsent(key, k -> supplier.get());
        }
    }
}
```

## 3.6.3 错误处理与异常管理 / Error Handling and Exception Management

### 数据验证 / Data Validation

**输入验证** / **Input Validation**:
- **数据类型检查** / **Data Type Checking**: 验证数据类型是否正确
- **数据范围检查** / **Data Range Checking**: 验证数据是否在有效范围内
- **数据完整性检查** / **Data Integrity Checking**: 检查数据是否完整
- **数据一致性检查** / **Data Consistency Checking**: 验证数据间的一致性

```java
public class DataValidationExample {
    public static void main(String[] args) {
        try {
            // 数据验证示例
            IVector validatedData = validateAndProcessData();
            createVisualization(validatedData);
        } catch (DataValidationException e) {
            System.err.println("数据验证失败: " + e.getMessage());
            handleValidationError(e);
        } catch (Exception e) {
            System.err.println("处理过程中发生错误: " + e.getMessage());
            handleGeneralError(e);
        }
    }
    
    private static IVector validateAndProcessData() throws DataValidationException {
        // 模拟数据输入
        float[] rawData = {1.0f, 2.0f, Float.NaN, 4.0f, 5.0f, -1.0f, 6.0f};
        
        // 数据验证
        validateDataTypes(rawData);
        validateDataRange(rawData);
        validateDataCompleteness(rawData);
        
        // 数据清理
        return cleanData(rawData);
    }
    
    private static void validateDataTypes(float[] data) throws DataValidationException {
        for (int i = 0; i < data.length; i++) {
            if (Float.isNaN(data[i]) || Float.isInfinite(data[i])) {
                throw new DataValidationException("数据包含无效值: " + data[i] + " at index " + i);
            }
        }
    }
    
    private static void validateDataRange(float[] data) throws DataValidationException {
        for (int i = 0; i < data.length; i++) {
            if (data[i] < 0 || data[i] > 100) {
                throw new DataValidationException("数据超出有效范围 [0, 100]: " + data[i] + " at index " + i);
            }
        }
    }
    
    private static void validateDataCompleteness(float[] data) throws DataValidationException {
        if (data == null || data.length == 0) {
            throw new DataValidationException("数据不能为空");
        }
    }
    
    private static IVector cleanData(float[] data) {
        // 数据清理：替换异常值
        for (int i = 0; i < data.length; i++) {
            if (Float.isNaN(data[i]) || Float.isInfinite(data[i])) {
                data[i] = 0.0f; // 用0替换异常值
            }
            if (data[i] < 0) {
                data[i] = 0.0f; // 用0替换负值
            }
        }
        return Linalg.vector(data);
    }
    
    private static void createVisualization(IVector data) {
        RerePlot plot = Plots.of(800, 600);
        plot.line(data);
        plot.setTitle("验证后的数据可视化", "经过验证和清理的数据");
        plot.saveAsHtml("validated_data_visualization.html");
    }
    
    private static void handleValidationError(DataValidationException e) {
        // 处理数据验证错误
        System.out.println("建议: 检查数据源，确保数据格式正确");
    }
    
    private static void handleGeneralError(Exception e) {
        // 处理一般错误
        System.out.println("建议: 联系技术支持或查看日志文件");
    }
    
    // 自定义异常类
    static class DataValidationException extends Exception {
        public DataValidationException(String message) {
            super(message);
        }
    }
}
```

### 异常恢复策略 / Exception Recovery Strategies

**错误恢复** / **Error Recovery**:
- **重试机制** / **Retry Mechanism**: 自动重试失败的操作
- **降级处理** / **Graceful Degradation**: 在部分功能失败时提供基本功能
- **备用方案** / **Fallback Options**: 提供备用的可视化方案
- **用户通知** / **User Notification**: 及时通知用户错误情况

```java
public class ExceptionRecoveryExample {
    private static final int MAX_RETRIES = 3;
    private static final long RETRY_DELAY = 1000; // 1秒
    
    public static void main(String[] args) {
        // 重试机制示例
        createVisualizationWithRetry();
        
        // 降级处理示例
        createVisualizationWithFallback();
    }
    
    private static void createVisualizationWithRetry() {
        for (int attempt = 1; attempt <= MAX_RETRIES; attempt++) {
            try {
                IVector data = loadDataWithPossibleFailure();
                RerePlot plot = Plots.of(800, 600);
                plot.line(data);
                plot.setTitle("重试成功", "第" + attempt + "次尝试成功");
                plot.saveAsHtml("retry_success.html");
                return; // 成功则退出
            } catch (Exception e) {
                System.err.println("第" + attempt + "次尝试失败: " + e.getMessage());
                if (attempt == MAX_RETRIES) {
                    System.err.println("所有重试都失败了");
                    createErrorVisualization(e);
                } else {
                    try {
                        Thread.sleep(RETRY_DELAY);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
        }
    }
    
    private static void createVisualizationWithFallback() {
        try {
            // 尝试创建复杂图表
            createComplexVisualization();
        } catch (Exception e) {
            System.err.println("复杂图表创建失败，使用简化版本: " + e.getMessage());
            // 降级到简化版本
            createSimpleVisualization();
        }
    }
    
    private static IVector loadDataWithPossibleFailure() throws Exception {
        // 模拟可能失败的数据加载
        if (Math.random() < 0.7) { // 70%概率失败
            throw new Exception("数据加载失败");
        }
        return Linalg.vector(new double[]{1, 2, 3, 4, 5});
    }
    
    private static void createComplexVisualization() throws Exception {
        // 模拟复杂图表创建
        if (Math.random() < 0.5) { // 50%概率失败
            throw new Exception("复杂图表创建失败");
        }
        
        RerePlot plot = Plots.of(800, 600);
        IVector data = Linalg.vector(new double[]{10, 20, 30, 40, 50});
        plot.line(data);
        plot.setTitle("复杂图表", "包含多种元素的复杂可视化");
        plot.saveAsHtml("complex_visualization.html");
    }
    
    private static void createSimpleVisualization() {
        RerePlot plot = Plots.of(800, 600);
        IVector data = Linalg.vector(new double[]{1, 2, 3, 4, 5});
        plot.line(data);
        plot.setTitle("简化图表", "降级后的简化可视化");
        plot.saveAsHtml("simple_visualization.html");
    }
    
    private static void createErrorVisualization(Exception e) {
        RerePlot plot = Plots.of(800, 600);
        IVector errorData = Linalg.vector(new double[]{0, 0, 0, 0, 0});
        plot.line(errorData);
        plot.setTitle("错误状态", "数据加载失败: " + e.getMessage());
        plot.saveAsHtml("error_visualization.html");
    }
}
```

## 3.6.4 代码质量与维护性 / Code Quality and Maintainability

### 代码组织 / Code Organization

**模块化设计** / **Modular Design**:
- **单一职责** / **Single Responsibility**: 每个类和方法只负责一个功能
- **松耦合** / **Loose Coupling**: 减少模块间的依赖关系
- **高内聚** / **High Cohesion**: 相关功能组织在一起
- **接口抽象** / **Interface Abstraction**: 使用接口定义抽象

```java
// 图表工厂接口
public interface ChartFactory {
    IPlot createChart(ChartType type, int width, int height);
    IPlot createChart(ChartType type, int width, int height, String theme);
}

// 图表工厂实现
public class YiShapeChartFactory implements ChartFactory {
    @Override
    public IPlot createChart(ChartType type, int width, int height) {
        RerePlot plot = Plots.of(width, height);
        return configureChart(plot, type);
    }
    
    @Override
    public IPlot createChart(ChartType type, int width, int height, String theme) {
        RerePlot plot = Plots.of(width, height, theme);
        return configureChart(plot, type);
    }
    
    private IPlot configureChart(IPlot plot, ChartType type) {
        switch (type) {
            case LINE:
                return plot;
            case BAR:
                return plot;
            case PIE:
                return plot;
            default:
                throw new IllegalArgumentException("不支持的图表类型: " + type);
        }
    }
}

// 图表类型枚举
public enum ChartType {
    LINE, BAR, PIE, SCATTER, HISTOGRAM, BOXPLOT
}

// 使用示例
public class ModularDesignExample {
    public static void main(String[] args) {

        IPlot lineChart = factory.createChart(ChartType.LINE, 800, 600);
        lineChart.line(Linalg.vector(new double[]{1, 2, 3, 4, 5}));
        lineChart.saveAsHtml("modular_line_chart.html");
        
        IPlot barChart = factory.createChart(ChartType.BAR, 800, 600, "dark");
        barChart.bar(Linalg.vector(new double[]{10, 20, 30, 40, 50}));
```

**配置外部化** / **Configuration Externalization**:
- **配置文件** / **Configuration Files**: 使用配置文件管理参数
- **环境变量** / **Environment Variables**: 使用环境变量管理敏感信息

```java
public class ConfigurationManagementExample {
    private static final Properties config = new Properties();
    
    static {
        loadConfiguration();
    }
    
    private static void loadConfiguration() {
        try (InputStream input = ConfigurationManagementExample.class
                .getClassLoader().getResourceAsStream("visualization.properties")) {
            if (input != null) {
                config.load(input);
            }
        } catch (IOException e) {
            System.err.println("配置文件加载失败，使用默认配置");
        }
    }
    
    public static void main(String[] args) {
        // 使用配置创建图表
        createConfiguredVisualization();
    }
    
    private static void createConfiguredVisualization() {
        // 从配置读取参数
        int width = getIntConfig("chart.width", 800);
        int height = getIntConfig("chart.height", 600);
        String theme = getStringConfig("chart.theme", "default");
        String title = getStringConfig("chart.title", "默认标题");
        
        // 创建图表
        RerePlot plot = Plots.of(width, height, theme);
        IVector data = Linalg.vector(new double[]{1, 2, 3, 4, 5});
        plot.line(data);
        plot.setTitle(title);
        plot.saveAsHtml("configured_chart.html");
    }
    
    private static int getIntConfig(String key, int defaultValue) {
        String value = config.getProperty(key);
        if (value != null) {
            try {
                return Integer.parseInt(value);
            } catch (NumberFormatException e) {
                System.err.println("配置值格式错误: " + key + " = " + value);
            }
        }
        return defaultValue;
    }
    
    private static String getStringConfig(String key, String defaultValue) {
        return config.getProperty(key, defaultValue);
    }
}
```

```java
    }

    public void testPerformanceWithLargeDataset() {
```

```java
public class MonitoringExample {
    private static final Logger logger = LoggerFactory.getLogger(MonitoringExample.class);
    private static final MeterRegistry meterRegistry = new SimpleMeterRegistry();
    
    public static void main(String[] args) {
        // 创建监控指标
        createMonitoringMetrics();
        
        // 执行可视化任务
        executeVisualizationTask();
    }
    
    private static void createMonitoringMetrics() {
        // 创建计时器
        Timer.Sample sample = Timer.start(meterRegistry);
        
        try {
            // 执行可视化任务
            IVector data = Linalg.vector(new double[]{1, 2, 3, 4, 5});
            RerePlot plot = Plots.of(800, 600);
            plot.line(data);
            plot.setTitle("监控示例", "带有性能监控的可视化");
            plot.saveAsHtml("monitoring_example.html");
            
            // 记录成功指标
            meterRegistry.counter("visualization.success").increment();
            
        } catch (Exception e) {
            // 记录错误指标
            meterRegistry.counter("visualization.error").increment();
            logger.error("可视化任务执行失败", e);
        } finally {
            // 记录执行时间
            sample.stop(Timer.builder("visualization.duration")
                    .register(meterRegistry));
        }
    }
    
    private static void executeVisualizationTask() {
        // 记录任务开始
        logger.info("开始执行可视化任务");
        
        try {
            // 模拟任务执行
            Thread.sleep(1000);
            
            // 记录任务完成
            logger.info("可视化任务执行完成");
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            logger.error("任务被中断", e);
        }
    }
}
```

## 3.6.7 常见误区

1. **用饼图比较超过 5 个分类**：人的眼睛无法准确判断多个扇区的大小——换堆叠柱状图
2. **Y 轴不从零开始**：会人为放大差异，让微小变化看起来触目惊心
3. **3D 图表**：看起来很炫，实际上最难读——除非你想炫耀显卡性能，否则用 2D
4. **颜色选择随意**：红绿色盲占男性 8%，色盲友好配色（蓝橙）更安全
