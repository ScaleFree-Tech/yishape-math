# 4.7 小结 / Summary

## 这一章学会了什么？

统计学的目标很简单：**用样本数据，判断总体真相，并且知道这个判断有多靠谱。**

学完这一章，你可以做到：

- **拿到数据不慌张**：先画分布图、看均值方差，而不是急着跑模型
- **听到「显著差异」会追问**：p 值是什么？样本量够不够？置信区间有多宽？
- **知道什么时候用什么分布**：均值推断用 t、方差推断用卡方、比较多组用 F——不是背的，是理解了原理
- **不再被「99% 置信区间」吓到**：置信区间不是概率，是反复抽样时有多少区间包含真值

## 4.7.1 本章内容回顾 / Chapter Content Review

### 4.1 抽样与极限定理 / Sampling and Limit Theorems

本章从统计学最基础的概念——**总体与样本**出发，建立了统计推断的认识论基础：

- **独立同分布（i.i.d.）假设**：是所有推断方法的出发点——样本之间无关联、样本与总体同分布
- **统计量**：样本的函数，不含未知参数。样本均值、方差、偏度、峰度等是最常用的统计量
- **大数定律（LLN）**：从数学上证明了"样本量越大，样本均值越接近总体均值"，赋予统计推断以理论合法性
- **中心极限定理（CLT）**：统计学中最重要的定理——无论总体分布如何，样本均值的抽样分布都趋于正态分布 $N(\mu, \sigma^2/n)$
- **三大抽样分布**：$\chi^2(k)$、$t(\nu)$、$F(d_1, d_2)$ 分别在方差推断、小样本均值推断、方差比较等场景中各有不可替代的作用

**YiShape-Math 工具**：`IDoubleVector.mean()/.var()/.skewness()/.kurtosis()`、`Stats.chi2()/.t()/.f()`

### 4.2 概率分布族 / Probability Distribution Families

概率分布是统计建模的基本构件。本章系统介绍了 YiShape-Math 实现的 14 种概率分布：

**连续型分布**：
- **正态分布 $N(\mu, \sigma^2)$**：统计学的核心分布，CLT 保证大量独立小因素之和趋于正态
- **t 分布**：小样本均值推断（$\sigma$ 未知时）的工具，尾部比正态分布更厚
- **卡方分布 $\chi^2(k)$**：方差推断的工具，由标准正态的平方和构成
- **F 分布 $F(d_1, d_2)$**：方差比较（ANOVA 的核心）的工具，由两个卡方之比构成
- **指数、Gamma、Beta、均匀**：分别在可靠性建模、比例推断、随机模拟等场景中使用

**离散型分布**：
- **伯努利 $Ber(p)$**：最基础的二分类分布
- **二项 $B(n, p)$**：固定次数独立试验中的成功计数
- **泊松 $P(\lambda)$**：稀有事件计数的建模工具

**统一接口设计**：`IContinuousDistribution`、`IDiscreteDistribution` 接口 + `Stats` 工厂类 = API 一致性

### 4.3 参数估计与假设检验 / Parameter Estimation and Hypothesis Testing

统计推断的两大核心问题：

**点估计**：
- **无偏性**：$E[\hat{\theta}] = \theta$ —— 估计量的期望等于真值
- **有效性**：无偏估计量中方差最小者为最优
- **一致性**：$n \to \infty$ 时 $\hat{\theta}_n \xrightarrow{P} \theta$
- **MLE**：最大似然估计——渐近无偏、渐近有效，具有不变性

**区间估计**：
- **置信区间**：不是"$\theta$ 以 $1-\alpha$ 概率落在区间内"，而是"重复抽样构造的区间中有 $1-\alpha$ 包含真值"
- **t 置信区间**：$\sigma$ 未知时，均值置信区间 $\bar{x} \pm t_{\alpha/2}(n-1) \cdot s/\sqrt{n}$
- **卡方置信区间**：方差置信区间 $\left[(n-1)s^2/\chi^2_{\alpha/2}, (n-1)s^2/\chi^2_{1-\alpha/2}\right]$

**假设检验**：
- **两类错误**：第一类（$\alpha$，虚报）和第二类（$\beta$，漏报）
- **p 值**：在 $H_0$ 下观察到当前或更极端数据的概率
- **单样本 t 检验**：均值是否等于某给定值
- **卡方拟合优度检验**：分类数据的分布是否符合预期

### 4.4 方差分析 / Analysis of Variance

当需要同时比较三个或更多总体均值时，ANOVA 是正确的工具：

**单因素 ANOVA**：
- **F 统计量**：$F = MSB/MSW \sim F(k-1, N-k)$
- **分解**：$SST = SSB + SSW$（总变异 = 组间变异 + 组内变异）
- **原理**：如果组间变异远大于组内变异，说明各组均值不全相等

**双因素 ANOVA**：
- **主效应**：控制其他因素后，某个因素的独立影响
- **交互效应**：两个因素的搭配产生的额外效果

**重复测量 ANOVA**：同一被试的多次测量，需要考虑被试间差异

**多重比较**：ANOVA 拒绝 $H_0$ 后用 Tukey HSD 确定具体哪些组存在差异

**前提条件**：正态性、方差齐性（可用 Levene 检验）

**YiShape-Math 工具**：`Stats.anova.performOneWayANOVA()/.performTwoWayANOVA()/.performRepeatedMeasuresANOVA()/.performTukeyHSD()`

### 4.5 贝叶斯推断 / Bayesian Inference

与频率学派并列的统计推断范式：

**贝叶斯定理**：后验 ∝ 似然 × 先验

**先验与后验**：
- **共轭先验**：后验与先验同分布族，计算简便
- **Beta-Binomial 共轭**：二项比例的贝叶斯估计
- **正态-正态共轭**：正态均值的贝叶斯估计

**后验分布的解读**：
- **点估计**：后验均值、后验众数（MAP）
- **可信区间**：直接概率解释（vs 频率学派置信区间的重复抽样解释）

**变分推断**：近似复杂后验分布的优化方法，当共轭先验无法使用时

**频率学派 vs 贝叶斯**：参数观不同（固定 vs 随机）、信息源不同（仅样本 vs 样本+先验）

### 4.6 应用案例 / Practical Application Cases

三个真实工业场景的综合应用：
- **质量控制**：单样本 t 检验 + 置信区间 + Cpk 指数
- **药物疗效**：双样本 t 检验 + 效应量（Cohen's d）+ 置信区间
- **用户留存**：二项比例的频率学派估计 + 贝叶斯后验分析

## 4.7.2 统计学在 YiShape-Math 中的实现特色 / Implementation Features

**1. 统一的工厂模式**

```java
NormalDistribution norm = Stats.norm(mean, stdDev);
StudentDistribution t = Stats.t(dof);
PoissonDistribution poisson = Stats.poisson(lambda);
```

无需记忆各分布的构造函数，通过 `Stats` 工厂类统一创建。

**2. 面向接口的设计**

```java
public interface IContinuousDistribution {
    double pdf(double x);
    double cdf(double x);
    double ppf(double p);
    double mean();
    double var();
    double[] sample(int n);
}
```

统一的接口保证了 API 一致性，便于扩展新分布。

**3. 统计方法与分布的协同**

```java
HypothesisTesting tester = Stats.tester;  // 假设检验
ParameterEstimation estimator = Stats.estimator;  // 参数估计
ANOVA anova = Stats.anova;  // 方差分析
```

三大统计方法模块与分布模块无缝衔接。

## 4.7.4 学习建议 / Learning Recommendations

1. **理论与代码并重**：理解数学公式后，用 YiShape-Math 运行代码验证结论
2. **从简单到复杂**：从单样本问题开始，逐步过渡到多组比较、多因素设计
3. **理解假设条件**：每种统计方法都有适用条件，违反假设时结果不可靠
4. **重视效应量**：统计显著性 ≠ 实际重要性，效应量帮助判断实际意义
5. **批判性思维**：看到结论时先问——这是统计显著还是只是数字巧合？
