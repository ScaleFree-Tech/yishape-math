## 开场：为什么贝叶斯后验分布算不出来？

在4.5节中，我们用贝叶斯定理 P(θ|D) ∝ P(D|θ)P(θ) 计算后验分布。但如果：

- P(D|θ) 是一个复杂的神经网络
- θ 是高维向量（100万个参数）
- P(θ|D) 没有解析形式

**怎么办？**

蒙特卡洛方法的思想是：**既然无法直接计算，就用随机抽样来"近似积分"**。

## 4.8.1 蒙特卡洛积分

### 4.8.1.1 什么是蒙特卡洛

对于任意函数 f(x)，求积分：

$$

I = \int_a^b f(x)dx

$$

经典数值方法：Newton-Cotes（将区间分段求和）。

蒙特卡洛方法：在 [a,b] 上随机抽样 {xᵢ}，则：

$$

\hat{I} = \frac{b-a}{N} \sum_{i=1}^{N} f(x_i) \xrightarrow{N \to \infty} I

$$

**优势**：收敛速度 O(1/√N)，与维度无关！对于高维积分，蒙特卡洛远比数值积分有效。

### 4.8.1.2 重要性抽样

如果 f(x) 在某处概率更大，应该在那里多抽样——这就是**重要性抽样（Importance Sampling）**的核心思想。

$$

I = \int f(x)p(x)dx = \int \frac{f(x)p(x)}{q(x)} q(x)dx \approx \frac{1}{N} \sum_{i=1}^{N} \frac{f(x_i)p(x_i)}{q(x_i)}

$$

其中 q(x) 是提议分布（proposal distribution）。

## 4.8.2 Metropolis-Hastings 采样

### 4.8.2.1 核心思想

Metropolis-Hastings（MH）算法的目标是：**从目标分布 π(x)（通常是后验分布）中抽样**。

步骤：
1. 从提议分布 q(x'|xₜ) 抽取候选样本 x*
2. 计算接受率 α = min{1, π(x*)q(xₜ|x*) / [π(xₜ)q(x*|xₜ)]}
3. 以概率 α 接受 x*，否则保留 xₜ

### 4.8.2.2 详细推导

**细致平衡条件**：如果 π(x)q(x'|x) = π(x')q(x|x')，则马尔可夫链收敛到 π。

MH接受率保证了这一点：

$$

P(x_t \to x^*) = q(x^*|x_t) \cdot \min\left(1, \frac{\pi(x^*)q(x_t|x^*)}{\pi(x_t)q(x^*|x_t)}\right)

$$

### 4.8.2.3 提议分布的选择

| 类型 | 例子 | 特点 |
|------|------|------|
| 随机游走 | x* = xₜ + ε, ε ~ N(0,σ²) | 简单，但接受率低 |
| 独立抽样 | q(x*\|xₜ) = q(x*) | 效率取决于 q 与 π 的接近程度 |
| 哈密顿动力学 | 利用梯度信息 | 接受率高，适合高维 |

```java
// MH 采样手动实现骨架（库未提供封装 API）
public class MHSampler {
    /** 目标分布的对数密度（未归一化即可） */
    public interface LogTarget {
        double logDensity(double x);
    }

    public static double[] sample(LogTarget target, int nSamples, int burnIn, double stepSize) {
        java.util.Random rng = new java.util.Random();
        double[] chain = new double[nSamples];
        double x = 0.0;  // 初始值

        for (int i = -burnIn; i < nSamples; i++) {
            double xStar = x + rng.nextGaussian() * stepSize;  // 随机游走提议
            double logAlpha = target.logDensity(xStar) - target.logDensity(x);
            if (Math.log(rng.nextDouble()) < logAlpha) {
                x = xStar;  // 接受
            }
            if (i >= 0) chain[i] = x;  // 丢弃 burn-in
        }
        return chain;
    }

    public static void main(String[] args) {
        // 对 Beta(3,4) 后验抽样（对数密度 ∝ 2*ln(x) + 3*ln(1-x)）
        double[] samples = sample(
            x -> 2 * Math.log(x) + 3 * Math.log(1 - x),
            10000, 1000, 0.1
        );

        // 后验均值估计
        double mean = java.util.Arrays.stream(samples).average().orElse(0);
        System.out.println("后验均值估计: " + mean);
    }
}
```

> **⚠️ 库未提供**：`Stats.bayes()` 及 `metropolisHastings(...)` 等 API **不存在**。上图为手动实现骨架，实际使用时需根据模型调整目标密度与提议分布。

> ⚠️ **常见误区**  
> **burn-in 不足**：马尔可夫链需要一段时间"预热"才能收敛到目标分布。如果 burn-in 太短，你的样本会受初始值影响。常用诊断：Trace Plot（应无明显趋势）+ Gelman-Rubin 统计量（应接近1.1）。

## 4.8.3 Gibbs 采样

### 4.8.3.1 条件分布抽样

当目标分布 π(x₁,x₂,...,xₙ) 的**条件分布** π(xᵢ|x_{-i}) 容易抽样时，Gibbs采样特别高效：

1. 初始化 (x₁⁰, x₂⁰, ..., xₙ⁰)
2. 对 i=1 到 n：
   - 从 π(xᵢ | x₁^{t+1}, ..., x_{i-1}^{t+1}, x_{i+1}^{t}, ..., xₙ^{t}) 抽取 xᵢ^{t+1}
3. 重复步骤2

**Gibbs采样的本质**：在高维空间，每次只更新一个维度，其他维度保持不变。

### 4.8.3.2 应用实例：GMM参数估计

对于高斯混合模型 (μ₁,μ₂,σ₁²,σ₂²,π) 的Gibbs采样：

```java
// Gibbs 采样概念骨架（库未提供封装 API）
// 以二维高斯 N(0, Σ) 为例，ρ = 0.9
public class GibbsSampler2D {
    public static void main(String[] args) {
        java.util.Random rng = new java.util.Random();
        int nSamples = 10000, burnIn = 1000;
        double rho = 0.9;

        double[] x1 = new double[nSamples];
        double[] x2 = new double[nSamples];
        double cur1 = 0, cur2 = 0;

        for (int i = -burnIn; i < nSamples; i++) {
            // 从条件分布采样：x1 | x2 ~ N(rho * x2, 1 - rho^2)
            cur1 = rng.nextGaussian() * Math.sqrt(1 - rho * rho) + rho * cur2;
            // 从条件分布采样：x2 | x1 ~ N(rho * x1, 1 - rho^2)
            cur2 = rng.nextGaussian() * Math.sqrt(1 - rho * rho) + rho * cur1;

            if (i >= 0) { x1[i] = cur1; x2[i] = cur2; }
        }

        double mean1 = java.util.Arrays.stream(x1).average().orElse(0);
        double mean2 = java.util.Arrays.stream(x2).average().orElse(0);
        System.out.println("E[x1] ≈ " + mean1 + ", E[x2] ≈ " + mean2);
    }
}
```

> **⚠️ 库未提供**：`Stats.bayes().gibbsSampler(...)` 不存在。Gibbs 采样需根据模型的条件分布手动实现。

## 4.8.4 Hamiltonian Monte Carlo（HMC）

### 4.8.4.1 物理直觉

HMC将参数 θ 视为"粒子位置"，引入"动量"变量 p。系统在势能 U(θ) = -log π(θ) 和动能 K(p) 下运动。

**哈密顿方程**：

$$

\frac{d\theta}{dt} = \frac{\partial H}{\partial p}, \quad \frac{dp}{dt} = -\frac{\partial H}{\partial \theta}

$$

其中 H(θ,p) = U(θ) + K(p)。

### 4.8.4.2 HMC的优势

| 对比项 | MH | HMC |
|--------|-----|-----|
| 接受率 | 低（高维时） | 高（~0.9） |
| 效率 | O(√d) | O(d^{1/4}) |
| 梯度使用 | ❌ | ✅ |

```java
// HMC 概念示意（库未提供封装 API，需依赖外部梯度计算）
// 以下仅为算法流程的伪代码骨架，不能直接运行

// 1. 定义势能 U(x) = -log π(x) 及其梯度 gradU(x)
// 2. 当前位置 x，采样动量 p ~ N(0, M)
// 3. 模拟 L 步 Leapfrog 积分：
//    p -= 0.5 * eps * gradU(x)
//    for l = 1..L:
//        x += eps * p / M
//        p -= eps * gradU(x)
//    p -= 0.5 * eps * gradU(x)
// 4. 计算接受率 α = min(1, exp(H(x,p) - H(x*,p*)))
// 5. 以概率 α 接受新状态

// 实际项目中，HMC 通常由 Stan、PyMC 等专业库实现；
// YiShape-Math 目前未提供 HMC/NUTS 封装。
```

> **⚠️ 库未提供**：`Stats.bayes().hamiltonianMonteCarlo(...)` 不存在。HMC 实现涉及自动微分与辛积分器，超出当前库范围。

> 📝 **历史故事**  
> HMC由 **Radford Neal**（2011）在《Handbook of Markov Chain Monte Carlo》中系统阐述。但其核心——利用哈密顿动力学加速抽样——来自 **Duane, Kennedy, Pendleton, Roweth（1987）** 在高能物理中的应用。Neal 后来在多伦多大学推广了HMC，现在是深度学习时代最重要的贝叶斯推理工具之一（Stan、PyMC3 都基于HMC）。

## 4.8.6 收敛诊断

### 4.8.6.1 Trace Plot

绘制参数样本序列——如果链在某个值附近"颤抖"（而非趋势或跳跃），则收敛。

### 4.8.6.2 Gelman-Rubin 统计量

比较多条链的方差：

$$

\hat{R} = \sqrt{\frac{\hat{V}}{W}}

$$

- \hat{R} < 1.1 → 收敛
- \hat{R} > 1.1 → 需要更多迭代

### 4.8.6.3 有效样本量（ESS）

马尔可夫链的相邻样本是相关的，有效样本量小于实际抽样数：

$$

ESS = \frac{N}{1 + 2\sum_{k=1}^{\infty} \rho_k}

$$

其中 ρ_k 是滞后k的自相关。

> **⚠️ 重要声明**：YiShape-Math **未提供** `Stats.bayes()` 及任何 MCMC 封装 API。本节所有采样算法（MH、Gibbs、HMC、NUTS）均以**概念性代码/手动实现**形式呈现。当前库中与贝叶斯推断相关的实际 API 仅限于：

| 功能 | 实际存在的 API | 说明 |
|------|---------------|------|
