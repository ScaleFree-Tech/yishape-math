# 4.8 马尔可夫链蒙特卡洛方法 / Markov Chain Monte Carlo

---

## 开场：为什么贝叶斯后验分布算不出来？

在4.5节中，我们用贝叶斯定理 P(θ|D) ∝ P(D|θ)P(θ) 计算后验分布。但如果：

- P(D|θ) 是一个复杂的神经网络
- θ 是高维向量（100万个参数）
- P(θ|D) 没有解析形式

**怎么办？**

蒙特卡洛方法的思想是：**既然无法直接计算，就用随机抽样来"近似积分"**。

> 📌 **学习目标**
> - 理解蒙特卡洛积分的基本思想
> - 掌握 Metropolis-Hastings 和 Gibbs 采样的原理
> - 了解 Hamiltonian Monte Carlo（HMC）的高效采样
> - 学会用 `Stats.bayes().mcmc()` 进行后验抽样

## 4.8.1 蒙特卡洛积分

### 4.8.1.1 什么是蒙特卡洛

对于任意函数 f(x)，求积分：

$$

I = \int_a^b f(x)dx

$$

经典数值方法：Newton-Cotes（将区间分段求和）。

蒙特卡洛方法：在 [a,b] 上随机抽样 {xᵢ}，则：

$$

\hat{I} = \frac{b-a}{N} \sum_{i=1}^{N} f(x_i) \xrightarrow{N \to \infty} I

$$

**优势**：收敛速度 O(1/√N)，与维度无关！对于高维积分，蒙特卡洛远比数值积分有效。

### 4.8.1.2 重要性抽样

如果 f(x) 在某处概率更大，应该在那里多抽样——这就是**重要性抽样（Importance Sampling）**的核心思想。

$$

I = \int f(x)p(x)dx = \int \frac{f(x)p(x)}{q(x)} q(x)dx \approx \frac{1}{N} \sum_{i=1}^{N} \frac{f(x_i)p(x_i)}{q(x_i)}

$$

其中 q(x) 是提议分布（proposal distribution）。

## 4.8.2 Metropolis-Hastings 采样

### 4.8.2.1 核心思想

Metropolis-Hastings（MH）算法的目标是：**从目标分布 π(x)（通常是后验分布）中抽样**。

步骤：
1. 从提议分布 q(x'|xₜ) 抽取候选样本 x*
2. 计算接受率 α = min{1, π(x*)q(xₜ|x*) / [π(xₜ)q(x*|xₜ)]}
3. 以概率 α 接受 x*，否则保留 xₜ

### 4.8.2.2 详细推导

**细致平衡条件**：如果 π(x)q(x'|x) = π(x')q(x|x')，则马尔可夫链收敛到 π。

MH接受率保证了这一点：

$$

P(x_t \to x^*) = q(x^*|x_t) \cdot \min\left(1, \frac{\pi(x^*)q(x_t|x^*)}{\pi(x_t)q(x^*|x_t)}\right)

$$

### 4.8.2.3 提议分布的选择

| 类型 | 例子 | 特点 |
|------|------|------|
| 随机游走 | x* = xₜ + ε, ε ~ N(0,σ²) | 简单，但接受率低 |
| 独立抽样 | q(x*\|xₜ) = q(x*) | 效率取决于 q 与 π 的接近程度 |
| 哈密顿动力学 | 利用梯度信息 | 接受率高，适合高维 |

```java
// MH采样示例
var sampler = Stats.bayes().metropolisHastings(
    target = posterior,       // 目标分布（未归一化的后验）
    proposal = "random_walk", // 提议分布类型
    proposalSD = 0.1          // 步长
);

double[][] samples = sampler.sample(10000, burnIn = 1000);
double meanTheta = Stats.math().mean(samples, 0);  // 参数均值估计
```

> ⚠️ **常见误区**  
> **burn-in 不足**：马尔可夫链需要一段时间"预热"才能收敛到目标分布。如果 burn-in 太短，你的样本会受初始值影响。常用诊断：Trace Plot（应无明显趋势）+ Gelman-Rubin 统计量（应接近1.1）。

## 4.8.3 Gibbs 采样

### 4.8.3.1 条件分布抽样

当目标分布 π(x₁,x₂,...,xₙ) 的**条件分布** π(xᵢ|x_{-i}) 容易抽样时，Gibbs采样特别高效：

1. 初始化 (x₁⁰, x₂⁰, ..., xₙ⁰)
2. 对 i=1 到 n：
   - 从 π(xᵢ | x₁^{t+1}, ..., x_{i-1}^{t+1}, x_{i+1}^{t}, ..., xₙ^{t}) 抽取 xᵢ^{t+1}
3. 重复步骤2

**Gibbs采样的本质**：在高维空间，每次只更新一个维度，其他维度保持不变。

### 4.8.3.2 应用实例：GMM参数估计

对于高斯混合模型 (μ₁,μ₂,σ₁²,σ₂²,π) 的Gibbs采样：

```java
// GMM的Gibbs采样
var sampler = Stats.bayes().gibbsSampler(
    data = observations,
    numComponents = 3
);

// 迭代采样
for (int iter = 0; iter < 10000; iter++) {
    sampler.sample();  // 一步迭代
}

// 丢弃前1000个样本（burn-in）
double[][] posteriorSamples = sampler.getSamples().subArray(1000, 10000);
double meanMu1 = Stats.math().mean(posteriorSamples, "mu1");
```

## 4.8.4 Hamiltonian Monte Carlo（HMC）

### 4.8.4.1 物理直觉

HMC将参数 θ 视为"粒子位置"，引入"动量"变量 p。系统在势能 U(θ) = -log π(θ) 和动能 K(p) 下运动。

**哈密顿方程**：

$$

\frac{d\theta}{dt} = \frac{\partial H}{\partial p}, \quad \frac{dp}{dt} = -\frac{\partial H}{\partial \theta}

$$

其中 H(θ,p) = U(θ) + K(p)。

### 4.8.4.2 HMC的优势

| 对比项 | MH | HMC |
|--------|-----|-----|
| 接受率 | 低（高维时） | 高（~0.9） |
| 效率 | O(√d) | O(d^{1/4}) |
| 梯度使用 | ❌ | ✅ |

```java
// HMC采样
var sampler = Stats.bayes().hamiltonianMonteCarlo(
    target = posterior,
    numLeapfrogSteps = 10,  // 步数
    stepSize = 0.01          // 步长
);

double[][] samples = sampler.sample(5000, burnIn = 1000);
```

> 📝 **历史故事**  
> HMC由 **Radford Neal**（2011）在《Handbook of Markov Chain Monte Carlo》中系统阐述。但其核心——利用哈密顿动力学加速抽样——来自 **Duane, Kennedy, Pendleton, Roweth（1987）** 在高能物理中的应用。Neal 后来在多伦多大学推广了HMC，现在是深度学习时代最重要的贝叶斯推理工具之一（Stan、PyMC3 都基于HMC）。

## 4.8.5 NUTS（No-U-Turn Sampler）

### 4.8.5.1 为什么要U-Turn检测

HMC需要手动设置步数和步长——设错了效率大打折扣。NUTS自动推断：

```java
// NUTS自动选择步数
var sampler = Stats.bayes().nuts(
    target = posterior,
    maxTreeDepth = 10  // 最大树深度
);
```

---

## 4.8.6 收敛诊断

### 4.8.6.1 Trace Plot

绘制参数样本序列——如果链在某个值附近"颤抖"（而非趋势或跳跃），则收敛。

### 4.8.6.2 Gelman-Rubin 统计量

比较多条链的方差：

$$

\hat{R} = \sqrt{\frac{\hat{V}}{W}}

$$

- \hat{R} < 1.1 → 收敛
- \hat{R} > 1.1 → 需要更多迭代

### 4.8.6.3 有效样本量（ESS）

马尔可夫链的相邻样本是相关的，有效样本量小于实际抽样数：

$$

ESS = \frac{N}{1 + 2\sum_{k=1}^{\infty} \rho_k}

$$

其中 ρ_k 是滞后k的自相关。

## 4.8.7 本节 API 一览

```java
// MH采样
var mh = Stats.bayes().metropolisHastings(target, proposal, stepSize);
double[][] samples = mh.sample(numSamples, burnIn);

// Gibbs采样
var gibbs = Stats.bayes().gibbsSampler(data, numComponents);
double[][] samples = gibbs.sample(numSamples, burnIn);

// HMC
var hmc = Stats.bayes().hamiltonianMonteCarlo(target, numLeapfrog, stepSize);
double[][] samples = hmc.sample(numSamples, burnIn);

// NUTS
var nuts = Stats.bayes().nuts(target, maxTreeDepth);
double[][] samples = nuts.sample(numSamples, burnIn);

// 收敛诊断
Stats.bayes().effectiveSampleSize(samples);     // ESS
Stats.bayes().gelmanRubin(chains);              // R统计量
```
