# 5.6 模型持久化 / Model Persistence

---

## 开场：训练好的模型，下次重启还能用吗？

你在本地训练了一个准确率 95% 的垃圾邮件分类器，关闭电脑后再次打开——模型还在吗？

**不能**。模型参数存在内存里，关机就消失了。

**模型持久化**（serialization）解决的就是这个问题：把训练好的模型保存到磁盘，下次直接加载使用。

> 📌 **学习目标**
> - 理解模型持久化的必要性
> - 掌握 `ML.saveClassifier()` / `ML.loadClassifier()` 的用法
> - 了解模型格式选择的工程考量
> - 学会处理模型加载中的版本兼容问题

---

## 5.6.1 为什么需要模型持久化

### 5.6.1.1 典型工作流

```
训练阶段:  数据 → 训练 → 模型 → 保存到 disk
部署阶段:  加载模型 ← 从 disk → 预测新数据
```

没有持久化 = **每次部署都需要重新训练**——这对时间和计算资源是巨大的浪费。

### 5.6.1.2 常见场景

| 场景 | 说明 |
|------|------|
| **离线训练 + 在线预测** | 训练在服务器，预测在边缘设备 |
| **实验对比** | 保存多个版本的模型，后续比较 |
| **模型更新** | A/B测试中切换不同版本的模型 |
| **协作共享** | 团队成员共享训练好的模型 |

## 5.6.2 YiShape-Math API

### 5.6.2.1 保存模型

```java
// 训练模型
var X = Linalg.matrix(trainingData);
var labels = Linalg.vector(labelArray);
var model = ML.logisticRegression(X, labels, lambda = 0.01);

// 保存到文件
ML.saveClassifier(model, "models/spam_classifier_v1.yishape");
```

### 5.6.2.2 加载模型

```java
// 加载模型
var model = ML.loadClassifier("models/spam_classifier_v1.yishape");

// 直接用于预测
var Xnew = Linalg.matrix(newData);
var predictions = model.predict(Xnew);
```

### 5.6.2.3 模型检查点

训练过程中定期保存中间结果：

```java
var model = ML.linearRegression(Xtrain, ytrain, lambda = 0.01);
for (int epoch = 0; epoch < 100; epoch++) {
    model.fit(Xtrain, ytrain);
    if (epoch % 10 == 0) {
        double valError = model.evaluate(Xval, yval);
        System.out.println("Epoch " + epoch + ": val error = " + valError);
        if (valError < bestError) {
            ML.saveClassifier(model, "checkpoints/best_model.yishape");
            bestError = valError;
        }
    }
}
```

## 5.6.3 模型格式选择

### 5.6.3.1 YiShape-Math 原生格式

`.yishape` 文件是 YiShape-Math 的二进制格式：

```java
// 保存
ML.saveClassifier(model, "model.yishape");

// 加载
var loaded = ML.loadClassifier("model.yishape");
```

**优势**：直接对应Java对象，无需额外转换  
**劣势**：与其他语言（Python、R）不兼容

### 5.6.3.2 JSON 格式（可读性）

对于需要跨平台或人工审查的场景：

```java
// 导出为JSON（需要用户实现）
String json = model.toJson();
Files.writeString(Path.of("model.json"), json);

// 加载
String json = Files.readString(Path.of("model.json"));
var model = Model.fromJson(json);
```

### 5.6.3.3 ONNX 格式（跨框架）

Open Neural Network Exchange (ONNX) 是模型互操作的标准：

```java
// 导出为ONNX（需要 YiShape-Math 1.2+）
model.exportOnnx("model.onnx");

// Python侧加载
// import onnxruntime as rt
// sess = rt.InferenceSession("model.onnx")
```

## 5.6.4 版本兼容与迁移

### 5.6.4.1 版本标签

保存时记录模型版本：

```java
var modelInfo = new java.util.HashMap<String, Object>();
modelInfo.put("version", "1.2.0");
modelInfo.put("trainingDate", LocalDate.now().toString());
modelInfo.put("accuracy", 0.952);
modelInfo.put("dataset", "spam_email_v3.csv");

ML.saveClassifier(model, "spam_v3.yishape", modelInfo);
```

### 5.6.4.2 加载时版本检查

```java
var model = ML.loadClassifier("spam_v3.yishape");
var info = model.getMetadata();
System.out.println("Model version: " + info.get("version"));
System.out.println("Trained on: " + info.get("trainingDate"));
```

> ⚠️ **常见误区**  
> **序列化安全问题**：反序列化未知来源的 `.yishape` 文件可能执行恶意代码（与 Java 的 `ObjectInputStream` 风险类似）。YiShape-Math 的 `.yishape` 格式经过签名验证，但**永远不要加载来自不可信来源的模型文件**。

## 5.6.5 大模型的分片存储

### 5.6.5.1 XGBoost 大模型

XGBoost 模型可能非常大（GB级别），可以分片存储：

```java
var xgbModel = ML.xGboost(Xtrain, ytrain, numTrees = 1000);

// 分片保存
xgbModel.saveSharded("xgboost_model_part", numShards = 4);
// → xgboost_model_part_0.yishape, ..., xgboost_model_part_3.yishape

// 加载
var loaded = XGBoostModel.loadSharded("xgboost_model_part", 4);
```

### 5.6.7 模型版本管理与 A/B 测试

在实际工程中，我们经常需要同时运行多个版本的模型，比较哪个效果更好。

```java
// 模型注册表
var registry = ML.modelRegistry();

// 保存多个版本
registry.register("spam-v1.0", modelV1);
registry.register("spam-v2.0", modelV2);
registry.register("spam-v2.1", modelV2_1);

// A/B 测试：各取 50% 流量
var abTest = registry.abTest("spam-v1.0", "spam-v2.0", trafficSplit = 0.5);

// 收集一周效果
abTest.run(days = 7);

// 提取结果
var results = abTest.evaluate();
System.out.println("v1.0 准确率: " + results.accuracy("spam-v1.0"));
System.out.println("v2.0 准确率: " + results.accuracy("spam-v2.0"));

// 自动选择胜者
if (results.significanceTest("spam-v2.0", pValue = 0.05)) {
    registry.setDefault("spam-v2.0");
    System.out.println("v2.0 显著优于 v1.0，已设为默认");
}
```

> 本节小结

本章涵盖了机器学习模型从训练到部署的完整生命周期。线性回归是最基础的监督学习算法，理解它有助于掌握所有其他算法的核心思想。正则化（Ridge/Lasso）通过约束模型复杂度防止过拟合，是所有机器学习算法的通用武器。

**核心要点**：
- 线性回归的 OLS 解：$\\hat{\beta} = (X^TX)^{-1}X^Ty$
- Ridge 加入 L2 正则项；Lasso 加入 L1 正则项（可做特征选择）
- 模型持久化让训练结果可以跨会话使用
- 版本管理支持在线实验和灰度发布
