# 5.7 数据预处理——垃圾进，垃圾出

> **📌 学习目标**
> - 理解为什么特征缩放是 ML 管线的必经步骤
> - 掌握 StandardScaler、MinMaxScaler、RobustScaler 的区别与适用场景
> - 学会用 OneHotEncoder、Binarizer、PolynomialFeatures 做特征工程
> - 能用 `ML.preproc` 构建完整的预处理流水线

## 开场：为什么你的模型效果差？

你花了三天调参，逻辑回归的准确率始终卡在 72%。隔壁同事用同样的数据，跑了个随机森林就到了 89%。

你怀疑自己模型选错了。但真正的问题可能更简单：**你没有做预处理。**

- 年龄是 0~100，收入是 0~1,000,000——尺度差了 4 个数量级。梯度下降会被收入维度「带跑」，完全忽略年龄的贡献。
- 部门是"销售""技术""运营"——字符串不能直接输入模型。你的模型看到的不是类别，是一堆乱码。

**预处理是 ML 管线中最不起眼但最关键的一步。** 好的预处理能让简单模型超越不做预处理的复杂模型。

## 5.7.1 特征缩放——让所有维度站在同一起跑线

### StandardScaler（Z-Score 标准化）

把每个特征变成**均值为 0、标准差为 1** 的分布：

$$z = \frac{x - \mu}{\sigma}$$

**适用场景**：逻辑回归、SVM、KNN、神经网络等基于距离或梯度的算法。

```java
import com.yishape.lab.math.ml.ML;
import com.yishape.lab.math.preprocessing.IRereScaler;

// 训练集上拟合 scaler，然后同时 transform 训练集和测试集
IRereScaler scaler = ML.preproc.standardScaler();
IMatrix XtrainScaled = scaler.fitTransform(Xtrain);
IMatrix XtestScaled  = scaler.transform(Xtest);  // 用训练集的均值/标准差！

// 可逆：还原原始尺度
IMatrix Xoriginal = scaler.inverseTransform(XtrainScaled);
```

> ⚠️ **关键陷阱**：`fit()` 只在训练集上执行！如果用全部数据（含测试集）一起 fit，会导致**数据泄露**——测试集的统计信息「渗入」了训练过程，评估指标虚高。

### MinMaxScaler（Min-Max 归一化）

把每个特征缩放到 `[0, 1]$ 区间：

$$x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

**适用场景**：神经网络（激活函数对输入范围敏感）、图像像素归一化。

```java
IRereScaler scaler = ML.preproc.minMaxScaler();           // 默认 [0, 1]
IRereScaler scaler2 = ML.preproc.minMaxScaler(0.0, 10.0); // 自定义范围 [0, 10]

IMatrix Xscaled = scaler.fitTransform(Xtrain);
```

### RobustScaler（鲁棒缩放）——有异常值时的救星

用**中位数**和 **IQR**（四分位距）代替均值和标准差，对异常值不敏感：

$$x_{\text{scaled}} = \frac{x - \text{median}}{Q_3 - Q_1}$$

**适用场景**：数据中有明显异常值（如传感器故障读数、极端收入值）。

```java
IRereScaler scaler = ML.preproc.robustScaler();
IMatrix Xscaled = scaler.fitTransform(Xtrain);
```

### 三种缩放器的选择口诀

| 数据特征 | 推荐缩放器 | 原因 |
|----------|-----------|------|
| 近似正态，无异常值 | StandardScaler | Z-score 最标准 |
| 有明显异常值 | RobustScaler | 中位数+IQR 不受异常值影响 |
| 神经网络 / 需要 [0,1] 范围 | MinMaxScaler | 严格控制输出范围 |
| 不确定 | 先画箱线图再决定 | 看看异常值有多严重 |

## 5.7.2 特征变换——让数据更「像」正态分布

### PolynomialFeatures（多项式特征）

把低维特征扩展为高维：$[x_1, x_2]$ → $[1, x_1, x_2, x_1^2, x_1 x_2, x_2^2]$

```java
// 生成 2 阶多项式特征（含交叉项）
var poly = ML.preproc.polynomialFeatures(2);
IMatrix Xpoly = poly.fitTransform(Xtrain);
// Xtrain 是 [n, 2] → Xpoly 变成 [n, 6]
```

> 💡 **什么时候需要多项式特征？** 当你怀疑特征之间有非线性关系时。比如「收入」和「年龄」单独看都是线性的，但「高收入 × 年轻」可能是一个强信号（年轻高收入人群的消费模式很特殊）。

### Binarizer（二值化）

把连续特征变成 0/1：

```java
// 阈值 = 0.5：大于 0.5 变 1，否则变 0
var binarizer = ML.preproc.binarizer(0.5);
IMatrix Xbin = binarizer.fitTransform(Xtrain);
```

### PowerTransformer（幂变换）

把偏态分布变「正态」——Yeo-Johnson 变换自动选择最优指数：

```java
var power = ML.preproc.powerTransformer();
IMatrix Xpower = power.fitTransform(Xtrain);
```

## 5.7.3 分类变量编码——让字符串变成数字

### OneHotEncoder（独热编码）

类别变量（部门、城市、产品类型）需要编码为数值。One-Hot 是最安全的方式：

```java
var encoder = ML.preproc.oneHotEncoder();
IMatrix Xencoded = encoder.fitTransform(Xtrain);
// "销售"→[1,0,0], "技术"→[0,1,0], "运营"→[0,0,1]
```

### LabelBinarizer（标签二值化）

二分类标签的编码：

```java
var labelEnc = ML.preproc.labelBinarizer();
// "是"/"否" → 1/0
IVector yEncoded = labelEnc.fitTransform(yLabels);
```

## 5.7.4 完整预处理管线：从原始数据到模型输入

把上面的步骤串起来，构建一个**可复用的预处理管线**：

```java
// ========== 加载数据 ==========
DataFrame raw = DataFrame.readCsv("customers.csv", ",", true);
var labelCol = raw.getColumnByName("is_churned");
var y = labelCol.toVec().map(v -> v > 0 ? 1.0 : 0.0);  // 标签

// ========== 选择特征列 ==========
DataFrame features = raw.selectByName("age", "income", "tenure", "department");

// ========== 编码分类变量 ==========
DataFrame numericOnly = features.selectByType(ColumnType.Numeric);
IMatrix Xnum = numericOnly.toMatrix();

// ========== 标准化 ==========
IRereScaler scaler = ML.preproc.standardScaler();
IMatrix Xscaled = scaler.fitTransform(Xnum);

// ========== 训练模型 ==========
var model = ML.clf.logisticRegression(0.0, 0.01);
model.fit(Xscaled, y);

// ========== 评估 ==========
var predictions = model.predict(Xscaled);
double auc = ClassificationMetrics.auc(y, predictions);
System.out.printf("AUC = %.4f%n", auc);
```

> **这就是 scikit-learn 的 Pipeline 在 YiShape-Math 中的等价物。** 虽然没有 `Pipeline` 类，但手动串联同样清晰——而且更透明，你能看到每一步做了什么。

## 5.7.5 本节 API 一览

| 预处理器 | API | 说明 |
|----------|-----|------|
| 标准化 | `ML.preproc.standardScaler()` | Z-score（均值0，标准差1） |
| 归一化 | `ML.preproc.minMaxScaler()` | Min-Max 缩放到 [0,1] |
| 鲁棒缩放 | `ML.preproc.robustScaler()` | 中位数+IQR，抗异常值 |
| 最大绝对值 | `ML.preproc.maxAbsScaler()` | 除以最大绝对值 |
| 行归一化 | `ML.preproc.normalizer()` | 逐样本 L2 归一化 |
| 多项式 | `ML.preproc.polynomialFeatures(degree)` | 生成多项式特征 |
| 二值化 | `ML.preproc.binarizer(threshold)` | 阈值二值化 |
| 独热编码 | `ML.preproc.oneHotEncoder()` | 分类变量 → 0/1 矩阵 |
| 标签编码 | `ML.preproc.labelBinarizer()` | 标签 → 0/1 |
| 幂变换 | `ML.preproc.powerTransformer()` | Yeo-Johnson 正态化 |
| 分位数变换 | `ML.preproc.quantileTransformer()` | 映射到均匀/正态分布 |
| 分箱 | `ML.preproc.bucketizer(nBins)` | 连续值 → 离散区间 |
