# 5.8 度量学习——让距离变得更聪明

> **📌 学习目标**
> - 理解欧氏距离的局限性和度量学习的核心动机
> - 掌握 Fisher 判别、LMNN、NCA 等经典度量学习算法的直觉
> - 能用 `ML.dml` 训练度量并改善 KNN 分类效果
> - 了解核化度量学习（Kernel DML）的应用场景

## 开场：为什么 KNN 的准确率上不去？

你用 KNN 做用户分类，选了 10 个特征（年龄、收入、活跃天数、消费金额……），准确率只有 70%。

问题出在哪？**KNN 用的是欧氏距离——它假设所有特征同等重要。**

但现实是：「消费金额」的数值范围是 0~100 万，「活跃天数」是 0~30。欧氏距离会被「消费金额」完全主导，「活跃天数」的信号被淹没。

度量学习的核心思想：**不改变数据本身，而是学习一个「更好的距离函数」**——让同类样本距离更近，异类样本距离更远。

---

## 5.8.1 从欧氏距离到马氏距离

### 欧氏距离的问题

$$d_{\text{Euclid}}(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_i (x_i - y_i)^2}$$

它隐含两个假设：
1. 所有维度同等重要
2. 维度之间不相关

但真实数据几乎不满足这两个假设。

### 马氏距离——考虑维度相关性

$$d_{\text{Mahal}}(\mathbf{x}, \mathbf{y}) = \sqrt{(\mathbf{x}-\mathbf{y})^\top \mathbf{M} (\mathbf{x}-\mathbf{y})}$$

其中 $\mathbf{M}$ 是一个**度量矩阵**（通常是半正定矩阵）。当 $\mathbf{M} = \mathbf{I}$ 时，马氏距离退化为欧氏距离。

**度量学习的本质**：学习最优的 $\mathbf{M}$，使分类/聚类效果最好。

---

## 5.8.2 经典度量学习算法

### Fisher 判别分析——类间最大，类内最小

Fisher 的思路最直觉：找一个投影方向，让**类间距离最大、类内距离最小**：

$$\max_{\mathbf{w}} \frac{\mathbf{w}^\top \mathbf{S}_B \mathbf{w}}{\mathbf{w}^\top \mathbf{S}_W \mathbf{w}}$$

其中 $\mathbf{S}_B$ 是类间散度矩阵，$\mathbf{S}_W$ 是类内散度矩阵。

```java
import com.yishape.lab.math.ml.ML;

// Fisher 白化：找到最优投影方向
var fisher = ML.dml.fisherWhitening();
var model = fisher.fit(Xtrain, ytrain);
IMatrix Xtransformed = model.transform(Xtest);
```

### LMNN（大间隔最近邻）——让 KNN 的邻居更靠谱

LMNN 的核心思想：对每个样本，**拉近 k 个同类邻居**，同时**推开异类样本**（保持一定间隔 margin）。

```java
// LMNN：rank=2（降到2维），每个样本找5个目标邻居，margin=1
var lmnn = ML.dml.lmnn(2, 5, 1.0);
var model = lmnn.fit(Xtrain, ytrain);
IMatrix XtrainNew = model.transform(Xtrain);
IMatrix XtestNew  = model.transform(Xtest);

// 现在用变换后的数据跑 KNN，准确率通常显著提升
```

### NCA（邻域成分分析）——概率化的距离学习

NCA 用概率模型学习距离：让每个样本**以高概率被同类邻居正确分类**。

```java
var nca = ML.dml.nca();  // 默认参数
var model = nca.fit(Xtrain, ytrain);
IMatrix XtrainNew = model.transform(Xtrain);
```

### ITML（信息论度量学习）——用约束定义距离

ITML 从**成对约束**（must-link / cannot-link）出发，通过最小化 Bregman 散度学习度量：

```java
// gamma=1.0（正则化强度），maxIter=1000（最大迭代）
var itml = ML.dml.itml(1.0, 1000);
var model = itml.fit(Xtrain, ytrain);
```

## 5.8.3 度量学习的通用 API 模式

所有 DML 算法共享统一的接口：

```java
// 1. 创建度量学习器
var dml = ML.dml.lmnn(2, 5, 1.0);  // 选择算法和参数

// 2. 训练
var model = dml.fit(Xtrain, ytrain);

// 3. 变换数据（应用学到的度量）
IMatrix XtrainNew = model.transform(Xtrain);
IMatrix XtestNew  = model.transform(Xtest);

// 4. 用变换后的数据跑下游任务（KNN / 聚类 / 可视化）
var knn = ML.clf.kNN(5);
knn.fit(XtrainNew, ytrain);
var predictions = knn.predict(XtestNew);
```

> 💡 **什么时候用度量学习？** 当你发现：
> - KNN / K-Means 效果不好，但不想换算法
> - 特征尺度差异大，标准化不够
> - 类别之间的边界不规则（非线性可分）

## 5.8.4 核化度量学习——处理非线性边界

当数据的最优度量是非线性的（比如环形分布），可以用核方法将数据映射到高维空间再学习度量：

```java
// 核化 LMNN：RBF 核，gamma=0.1
var klmnn = ML.dml.klmnn(KernelType.RBF, 0.1, 2, 1.0);
var model = klmnn.fit(Xtrain, ytrain);
```

常见核类型：
- `KernelType.RBF`：径向基核，最通用
- `KernelType.POLY`：多项式核
- `KernelType.LINEAR`：线性核（等价于无核）

## 5.8.5 本节 API 一览

| 算法 | API | 适用场景 |
|------|-----|---------|
| Fisher 白化 | `ML.dml.fisherWhitening()` | 二分类降维，最大化类间分离 |
| RCA | `ML.dml.rca()` | 相关成分分析，适合噪声数据 |
| 类内缩放 | `ML.dml.withinClass()` | 简单的类内方差归一化 |
| ITML | `ML.dml.itml(gamma, maxIter)` | 有成对约束时 |
| NCA | `ML.dml.nca(rank, maxIter, lr)` | 概率化距离学习 |
| MCML | `ML.dml.mcml(rank, maxIter, lr)` | 成对约束 + 概率化 |
| LMNN | `ML.dml.lmnn(rank, k, margin)` | KNN 改进首选 |
| 对角 DML | `ML.dml.diagDml(l1, l2)` | 可解释性要求高（只学维度权重） |
| DML-eig | `ML.dml.dmleig(mu, maxIter)` | 广义特征值求解 |
| DML-MJ | `ML.dml.dmlmj(numDims, k)` | Jeffrey 散度度量 |
| GMML | `ML.dml.geodesicStep, reg` | 几何均值度量 |
| LLDA | `ML.dml.llda(nComponents)` | 局部 Fisher 判别分析 |
| KDA | `ML.dml.kda(kernel, gamma, n)` | 核判别分析 |
| 在线 DML | `ML.dml.odml(lr, aggression)` | 流式数据 |
| CNN/RNN | `ML.dml.cnn()` / `ML.dml.rnn()` | 最近邻精简 |
