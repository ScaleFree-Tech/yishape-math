# 6.6 多目标优化——鱼和熊掌怎么兼得？

> **📌 学习目标**
> - 理解多目标优化与单目标优化的本质区别
> - 掌握 Pareto 最优的核心概念
> - 能用 `Opts.mclp` 和 `Opts.mcqp` 求解多目标问题
> - 了解加权和法、epsilon 约束法的适用场景

## 开场：你要同时省钱和提速，怎么办？

你是一家物流公司的调度经理。老板给了两个目标：

1. **成本最小**：运输费用越低越好
2. **速度最快**：配送时间越短越好

问题是：**省钱和提速是矛盾的。** 选最快的路线（高速公路），油费高；选最便宜的路线（国道），时间长。

这就是**多目标优化**（Multi-Objective Optimization，MOO）的典型场景：多个目标相互冲突，不存在一个「完美解」让所有目标同时最优。

---

## 6.6.1 Pareto 最优——什么叫「已经很好了」？

### 核心定义

在多目标优化中，**Pareto 最优解**（也叫非支配解）是指：

> 不存在另一个解，能在**不损害任何目标**的前提下，让至少一个目标变得更好。

换句话说：**你已经无法在不牺牲某个目标的情况下改进另一个目标了。**

### 直觉理解

假设你在选手机：

| 方案 | 价格（元） | 性能分 |
|------|-----------|--------|
| A | 3000 | 85 |
| B | 2500 | 80 |
| C | 3500 | 82 |
| D | 2000 | 75 |

- A 支配 C：A 既便宜（3000 < 3500）性能又高（85 > 82），C 没有存在价值
- B 支配 D：B 便宜且性能高
- **A 和 B 之间无法互相支配**——A 性能更好但更贵，B 更便宜但性能差

所以 A 和 B 都是 Pareto 最优解，C 和 D 被支配（可以淘汰）。

### Pareto 前沿

所有 Pareto 最优解构成的集合叫 **Pareto 前沿**（Pareto Front）。在二维目标空间中，它通常是一条从左上到右下的曲线：

```
性能 ↑
     A ●
       \
        \  ← Pareto 前沿
         \
          B ●
     D ●
       C ●（被支配）
     ──────────→ 价格
```

## 6.6.2 加权求和法——最直觉的方法

把多个目标合并为一个：$f = w_1 \cdot f_1 + w_2 \cdot f_2$

通过调整权重 $w_1, w_2$，可以得到 Pareto 前沿上的不同点。

```java
import com.yishape.lab.math.optimize.Opts;
import com.yishape.lab.math.linalg.IMatrix;
import com.yishape.lab.math.linalg.IVector;
import com.yishape.lab.math.linalg.Linalg;

// 多目标线性规划：两个目标
// 目标1：最小化成本 c₁ᵀx
// 目标2：最小化时间 c₂ᵀx
IVector c1 = Linalg.vector(new double[]{3.0, 5.0, 2.0});  // 成本系数
IVector c2 = Linalg.vector(new double[]{1.0, 2.0, 4.0});  // 时间系数

// 约束：x₁ + x₂ + x₃ ≤ 100, xᵢ ≥ 0
IMatrix A = Linalg.matrix(new double[][]{{1, 1, 1}});
IVector b = Linalg.vector(new double[]{100.0});

// 加权和：70% 看成本，30% 看时间
IVector weights = Linalg.vector(new double[]{0.7, 0.3});
var result = Opts.mclp.weightedSumMclp(weights, new IVector[]{c1, c2}, A, b);

System.out.println("最优解: " + result.getOptimalPoint());
System.out.println("目标值: " + result.getOptimalValue());
```

### 权重敏感性分析

通过系统地改变权重，可以扫描整个 Pareto 前沿：

```java
// 权重从 (1.0, 0.0) 到 (0.0, 1.0)，步长 0.1
for (double w1 = 0.0; w1 <= 1.0; w1 += 0.1) {
    double w2 = 1.0 - w1;
    IVector weights = Linalg.vector(new double[]{w1, w2});
    var result = Opts.mclp.weightedSumMclp(weights, new IVector[]{c1, c2}, A, b);
    System.out.printf("w=(%.1f, %.1f) → 成本=%.2f, 时间=%.2f%n",
        w1, w2,
        c1.innerProduct(result.getOptimalPoint()),
        c2.innerProduct(result.getOptimalPoint()));
}
```

## 6.6.3 多目标二次规划（MOQP）

当目标函数包含二次项（如方差最小化）时，用 `Opts.mcqp`：

```java
// 多目标二次规划
// 目标1：min xᵀQ₁x + c₁ᵀx
// 目标2：min xᵀQ₂x + c₂ᵀx
IMatrix Q1 = Linalg.eye(3);   // 单位矩阵（简化示例）
IMatrix Q2 = Linalg.eye(3);
IVector c1qp = Linalg.vector(new double[]{1.0, 2.0, 3.0});
IVector c2qp = Linalg.vector(new double[]{3.0, 2.0, 1.0});

IVector weights = Linalg.vector(new double[]{0.5, 0.5});
var result = Opts.mcqp.weightedSumQp(weights,
    new IMatrix[]{Q1, Q2},
    new IVector[]{c1qp, c2qp},
    A, b);
```

## 6.6.4 epsilon 约束法——固定一个目标，优化另一个

不用加权求和，而是**把一个目标转为约束**：

$$\min f_1(x) \quad \text{s.t.} \quad f_2(x) \leq \epsilon$$

通过改变 $\epsilon$，扫描 Pareto 前沿。

```java
// epsilon 约束法：固定时间上限，最小化成本
double epsilon = 50.0;  // 时间不超过 50
// 约束变为：Aeq * x = beq, 且 c2ᵀx ≤ epsilon
// 需要手动将 c2ᵀx ≤ epsilon 加入约束矩阵
```

## 6.6.5 什么时候用什么方法？

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **加权和法** | 简单直观 | 权重选择主观；无法找到非凸前沿上的点 | 目标函数凸、快速求解 |
| **epsilon 约束法** | 可找到非凸前沿 | 需要多次求解；epsilon 选择困难 | 需要精确 Pareto 前沿 |
| **Pareto 扫描** | 完整前沿 | 计算量大 | 离线分析、决策支持 |

## 6.6.6 真实案例：投资组合优化

投资者希望同时**最大化收益**和**最小化风险**：

```java
// 5 只股票的预期收益率
IVector returns = Linalg.vector(new double[]{0.12, 0.08, 0.15, 0.06, 0.10});
// 协方差矩阵（风险）
IMatrix cov = Linalg.matrix(new double[][]{
    {0.04, 0.006, 0.01, 0.002, 0.005},
    {0.006, 0.025, 0.008, 0.003, 0.004},
    {0.01, 0.008, 0.06, 0.001, 0.007},
    {0.002, 0.003, 0.001, 0.015, 0.002},
    {0.005, 0.004, 0.007, 0.002, 0.03}
});

// 约束：权重之和 = 1，每只股票权重 ≥ 0
IVector oneVec = Linalg.vector(new double[]{1, 1, 1, 1, 1});
IMatrix Aeq = Linalg.matrix(new double[][]{{1, 1, 1, 1, 1}});
IVector beq = Linalg.vector(new double[]{1.0});

// 加权和：权衡收益与风险
IVector weights = Linalg.vector(new double[]{0.6, 0.4});  // 60% 收益偏好
var result = Opts.mcqp.weightedSumQp(weights,
    new IMatrix[]{cov},        // 目标1：最小化风险（二次项）
    new IVector[]{returns},     // 目标2：最大化收益（线性项，取负变最小化）
    Aeq, beq);

System.out.println("最优配置: " + result.getOptimalPoint());
```

## 6.6.7 本节 API 一览

| 方法 | API | 说明 |
|------|-----|------|
| 加权和 MCLP | `Opts.mclp.weightedSumMclp(weights, objectives, A, b)` | 多目标线性规划 |
| 加权和 MCQP | `Opts.mcqp.weightedSumQp(weights, Qs, cs, A, b)` | 多目标二次规划 |

> **MCLP** = Multi-Objective Linear Programming，**MCQP** = Multi-Objective Quadratic Programming
