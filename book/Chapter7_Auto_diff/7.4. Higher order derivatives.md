# 7.4 高阶导数与混合模式

> **本节目标**：掌握高阶导数的计算——tape-of-tape 机制、grad() 的符号梯度、以及 MixedMode 的完整用法。


## 1. 为什么需要高阶导数

一阶导数（梯度）告诉你「哪个方向下降最快」。二阶导数（Hessian）告诉你「下降有多快、曲面有多弯」。许多高级算法需要二阶信息：

| 算法 | 需要的导数 | 用途 |
|------|-----------|------|
| **牛顿法** | Hessian（二阶） | 二阶收敛速度 |
| **Fisher 信息矩阵** | 期望 Hessian | 自然梯度下降 |
| **元学习（MAML）** | 梯度的梯度 | 学习如何学习 |
| **对抗训练** | 梯度的梯度 | 生成对抗样本 |


## 2. tape-of-tape：梯度的梯度

YiShape-Math 使用 **tape-of-tape** 机制实现高阶微分：**将梯度本身也构建为可微计算图**。

```java
IDiffVector x = AD.vector(2.0);

// 一阶：计算 ∂f/∂x
IDiffVector y = x.pow(4).sum();       // y = x⁴
IDiffVector[] grads = AD.grad(y, x);  // grads[0] 是 ∂y/∂x 的符号节点
IDiffVector dy = grads[0];            // dy = 4x³

// 二阶：对 ∂y/∂x 再求导
IDiffVector[] grads2 = AD.grad(dy, x);
IDiffVector d2y = grads2[0];          // d2y = 12x²

// 验证：12 × 4 = 48
System.out.println(d2y.getValue());   // 48.0
```

### AD.grad() 的核心思想

`AD.grad(output, inputs)` 不立即执行反向传播，而是返回**符号梯度节点**。这些节点本身也是可微的——对它们再调用 `AD.grad()` 就能得到高阶导数。


## 3. grad() vs backward()

| 方法 | 行为 | 返回值 | 用途 |
|------|------|--------|------|
| `.backward()` | 执行反向传播，填充叶子节点的梯度 | `void` | 一阶梯度 |
| `AD.grad(y, x)` | 返回符号梯度节点，不填充 | `IDiffVector[]` | 高阶导数 |

```java
IDiffVector x = AD.vector(1.0, 2.0);
IDiffVector y = x.pow(2).sum();

// backward()：直接填充梯度
y.backward();
IVector grad1 = x.getGradient();  // [2.0, 4.0]

// grad()：返回符号节点
x.zeroGradient();
y.zeroGradient();
IDiffVector[] symGrad = AD.grad(y, x);
IDiffVector gradNode = symGrad[0];  // gradNode 的 value 就是梯度
System.out.println(gradNode.getValue());  // [2.0, 4.0]
```


## 4. MixedMode 完整 API

### 4.1 HVP（Hessian-向量积）

HVP 是最常用的二阶微分工具。它用 tape-of-tape 实现：先 `grad()` 再 `dot(v)` 再 `backward()`。

```java
Function<IDiffVector, IDiffVector> lossFn = x -> {
    // Rosenbrock 函数：f = (1-x₁)² + 100(x₂-x₁²)²
    IDiffVector x1 = x.slice(0, 1);
    IDiffVector x2 = x.slice(1, 2);
    IDiffVector a = AD.vector(1.0).sub(x1).square();
    IDiffVector b = x2.sub(x1.mul(x1)).square().mul(AD.vector(100.0));
    return a.add(b);
};

IDiffVector x = AD.vector(0.0, 0.0);
IDoubleVector v = Linalg.vector(1.0, 0.0);

// HVP = H @ v
double[] hvp = MixedMode.hvp(lossFn, x, v);
System.out.println(Linalg.vector(hvp));
```

### 4.2 JVP（Jacobian-向量积）

JVP 使用正向模式 AD（`TangentDiffVector`），无需存储计算图：

```java
Function<IDiffVector, IDiffVector> fn = x -> {
    IDiffVector x1 = x.slice(0, 1);
    IDiffVector x2 = x.slice(1, 2);
    return Linalg.vector(
        x1.sin().mul(x2),
        x1.mul(x2.cos())
    ).flatten();
};

IDiffVector x = AD.vector(1.0, 2.0);
IDoubleVector v = Linalg.vector(1.0, 0.0);

double[] jvp = MixedMode.jvp(fn, x, v);
// JVP = J @ [1, 0]^T = 第一列 Jacobian
```

### 4.3 完整 Hessian

```java
Function<IDiffVector, IDiffVector> lossFn = x -> x.pow(4).sum();

IDiffVector x = AD.vector(1.0, 2.0, 3.0);
IDoubleMatrix H = MixedMode.hessian(lossFn, x);

// H = diag(12x₁², 12x₂², 12x₃²)
// = diag(12, 48, 108)
System.out.println(H);
```

### 4.4 完整 Jacobian

```java
Function<IDiffVector, IDiffVector> fn = x -> {
    IDiffVector x1 = x.slice(0, 1);
    IDiffVector x2 = x.slice(1, 2);
    return Linalg.vector(
        x1.mul(x1).add(x2.mul(x2)),
        x1.mul(x2)
    ).flatten();
};

IDiffVector x = AD.vector(1.0, 2.0);
IDoubleMatrix J = MixedMode.jacobianFull(fn, x);

// J = [[2x₁, 2x₂],  =  [[2, 4],
//      [x₂,   x₁ ]]     [2, 1]]
```


## 5. VJP：向量-Jacobian 积

VJP 是反向传播的推广形式——它计算 $J^T \cdot g$，其中 $g$ 是上游梯度：

```java
Function<IDiffVector, IDiffVector> fn = x -> {
    IDiffVector x1 = x.slice(0, 1);
    IDiffVector x2 = x.slice(1, 2);
    return Linalg.vector(
        x1.mul(x1).add(x2),
        x1.mul(x2.mul(x2))
    ).flatten();
};

IDiffVector x = AD.vector(1.0, 2.0);
IDoubleVector upstream = Linalg.vector(1.0, 1.0);

double[] vjp = MixedMode.vjp(fn, x, upstream);
// VJP = J^T @ [1, 1]^T
```


## 6. 实战：MAML 元学习的核心

MAML（Model-Agnostic Meta-Learning）需要「梯度的梯度」：

```java
// 内层任务损失
Function<IDiffVector, IDiffVector> taskLoss = params -> {
    IDiffVector pred = params.slice(0, 1).mul(AD.vector(2.0));
    return pred.sub(AD.vector(1.0)).square();
};

// 外层元损失 = 对内层梯度求导
IDiffVector params = AD.vector(0.0);

// 一步梯度下降后的参数
IDiffVector[] grads = AD.grad(taskLoss.apply(params), params);
IDiffVector updatedParams = params.sub(grads[0].mul(AD.vector(0.1)));

// 元损失
IDiffVector metaLoss = taskLoss.apply(updatedParams);
IDiffVector[] metaGrads = AD.grad(metaLoss, params);
System.out.println("元梯度: " + metaGrads[0].getValue());
```


## 7. 本节小结

| API | 用途 | 复杂度 |
|-----|------|--------|
| `AD.grad(y, x)` | 符号梯度节点（可微） | O(前向) |
| `MixedMode.hvp(fn, x, v)` | Hessian-向量积 | O(前向 + 反向) |
| `MixedMode.hessian(fn, x)` | 完整 Hessian | O(n × (前向 + 反向)) |
| `MixedMode.jvp(fn, x, v)` | Jacobian-向量积 | O(前向) |
| `MixedMode.vjp(fn, x, g)` | Vector-Jacobian 积 | O(反向) |
| `MixedMode.jacobianFull(fn, x)` | 完整 Jacobian | O(n × 前向) |
