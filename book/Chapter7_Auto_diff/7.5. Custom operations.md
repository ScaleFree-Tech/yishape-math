# 7.5 自定义算子：CustomOp

> **本节目标**：掌握自定义算子的前向/反向实现——当内置运算不够用时，如何扩展自动微分系统。


## 1. 为什么需要自定义算子

内置算子覆盖了常见的数学运算（加减乘除、激活函数等），但有些场景需要自己定义前向和反向逻辑：

- **自定义激活函数**（如 Swish、Mish 的变体）
- **自定义损失函数**（如 Focal Loss、CIoU Loss）
- **数值稳定的特殊运算**（如 log-sum-exp）
- **与外部库的桥接**（如调用 GPU Kernel）


## 2. CustomOp：推荐的自定义算子 API

`CustomOp` 是推荐的自定义算子抽象类，取代了废弃的全局注册模式：

```java
public abstract class CustomOp {
    // 前向计算（子类实现）
    protected abstract ForwardResult forward(IDoubleVector[] rawInputs);

    // 反向计算（子类实现）
    protected abstract IDoubleVector[] backward(IDoubleVector gradOutput, Object forwardContext);

    // 构建计算图节点
    public IDiffVector apply(IDiffVector... inputs);

    // 前向结果记录
    public record ForwardResult(IDoubleVector output, Object context) {}
}
```


## 3. 示例：Softplus 激活函数

Softplus：$f(x) = \ln(1 + e^x)$，导数：$f'(x) = \sigma(x) = \frac{1}{1+e^{-x}}$

```java
public class SoftplusOp extends CustomOp {
    @Override
    protected ForwardResult forward(IDoubleVector[] rawInputs) {
        IDoubleVector x = rawInputs[0];
        // 前向：softplus(x) = log(1 + exp(x))
        // 使用数值稳定版本：max(x,0) + log(1 + exp(-|x|))
        double[] result = new double[x.size()];
        for (int i = 0; i < x.size(); i++) {
            double xi = x.get(i);
            result[i] = Math.max(xi, 0) + Math.log(1 + Math.exp(-Math.abs(xi)));
        }
        return new ForwardResult(Linalg.vector(result), null);
    }

    @Override
    public IDoubleVector[] backward(IDoubleVector gradOutput, Object context) {
        // 反向：∂softplus/∂x = sigmoid(x)
        double[] x = ((IDoubleVector) context).toArray();
        double[] gradInput = new double[x.length];
        for (int i = 0; i < x.length; i++) {
            double sig = 1.0 / (1.0 + Math.exp(-x[i]));
            gradInput[i] = gradOutput.get(i) * sig;
        }
        return new IDoubleVector[]{Linalg.vector(gradInput)};
    }
}

// 使用
IDiffVector x = AD.vector(-1.0, 0.0, 1.0);
IDiffVector y = new SoftplusOp().apply(x);
y.backward();
System.out.println(x.getGradient());
```

### 关键点

1. **`forward()` 接收原始 `double[]`**，不参与计算图——前向只计算值
2. **`backward()` 接收上游梯度**，返回每个输入的梯度贡献
3. **`context` 参数**用于在前向和反向之间传递信息（如保存中间值）


## 4. 示例：Focal Loss

Focal Loss 用于解决类别不平衡问题：

$$\text{FL}(p_t) = -\alpha_t (1-p_t)^\gamma \log(p_t)$$

```java
public class FocalLossOp extends CustomOp {
    private final double gamma;
    private final double alpha;

    public FocalLossOp(double gamma, double alpha) {
        this.gamma = gamma;
        this.alpha = alpha;
    }

    @Override
    protected ForwardResult forward(IDoubleVector[] rawInputs) {
        IDoubleVector probs = rawInputs[0];    // p(t)
        IDoubleVector targets = rawInputs[1];  // 0 或 1

        double loss = 0;
        double[] savedProbs = new double[probs.size()];
        double[] savedTargets = new double[targets.size()];

        for (int i = 0; i < probs.size(); i++) {
            double p = Math.max(1e-7, Math.min(1 - 1e-7, probs.get(i)));
            double t = targets.get(i);
            savedProbs[i] = p;
            savedTargets[i] = t;
            double fl = -alpha * Math.pow(1 - p, gamma) * Math.log(p) * t
                       - (1 - alpha) * Math.pow(p, gamma) * Math.log(1 - p) * (1 - t);
            loss += fl;
        }

        return new ForwardResult(Linalg.vector(loss / probs.size()),
            new Object[]{Linalg.vector(savedProbs), Linalg.vector(savedTargets)});
    }

    @Override
    public IDoubleVector[] backward(IDoubleVector gradOutput, Object context) {
        Object[] saved = (Object[]) context;
        IDoubleVector probs = (IDoubleVector) saved[0];
        IDoubleVector targets = (IDoubleVector) saved[1];

        double g = gradOutput.get(0);
        double[] gradP = new double[probs.size()];
        double n = probs.size();

        for (int i = 0; i < n; i++) {
            double p = probs.get(i);
            double t = targets.get(i);
            // ∂FL/∂p 的解析导数（省略常数项）
            double dp = -alpha * gamma * Math.pow(1-p, gamma-1) * (-1) * Math.log(p) * t
                      + alpha * Math.pow(1-p, gamma) * (1/p) * t
                      - (1-alpha) * gamma * Math.pow(p, gamma-1) * Math.log(1-p) * (1-t)
                      + (1-alpha) * Math.pow(p, gamma) * (1/(1-p)) * (1-t);
            gradP[i] = g * dp / n;
        }

        return new IDoubleVector[]{Linalg.vector(gradP), Linalg.vector(new double[probs.size()])};
    }
}

// 使用
IDiffVector probs = AD.vector(0.9, 0.1, 0.8);
IDiffVector targets = AD.vector(1.0, 0.0, 1.0);
IDiffVector loss = new FocalLossOp(2.0, 0.25).apply(probs, targets);
loss.backward();
System.out.println(probs.getGradient());
```


## 5. 张量版：TensorCustomOp

对于多维张量运算，使用 `TensorCustomOp`：

```java
public class MyTransposeOp extends TensorCustomOp {
    @Override
    protected ForwardResult forward(IDoubleTensor[] rawInputs) {
        IDoubleTensor x = rawInputs[0];
        // 转置逻辑
        IDoubleTensor result = x.permute(1, 0);
        return new ForwardResult(result, null);
    }

    @Override
    public IDoubleTensor[] backward(IDoubleTensor gradOutput, Object context) {
        // 转置的反向 = 转置
        return new IDoubleTensor[]{gradOutput.permute(1, 0)};
    }
}
```


## 6. 复数自动微分：Wirtinger 微积分

YiShape-Math 支持基于 **Wirtinger 微积分** 的可微复向量：

```java
// 创建可微复向量
IComplexVector cData = Linalg.complexVector(
    new double[]{1, 0},   // 实部
    new double[]{0, 1}    // 虚部
);
IDiffComplex z = AD.complex(cData);

// 复数运算
IDiffComplex w = z.mul(z).add(z.conjugate());
w.backward();

// 获取复梯度
IComplexVector grad = z.getGradient();
```


## 7. 废弃 API 说明

早期版本使用全局注册表 `CustomGradientRegistry`：

```java
// 已废弃，不推荐
AD.registerGradient("myOp", gradFn);
IDiffVector y = AD.custom("myOp", forwardFn, x);
```

**废弃原因**：
- 全局注册表导致内存泄漏（无法 GC 不再使用的反向函数）
- 线程不安全（多线程同时注册会冲突）
- 调试困难（无法追踪算子来源）

**推荐做法**：使用 `CustomOp` 或 `TensorCustomOp`，无全局状态，无内存泄漏。


## 8. 本节小结

| API | 用途 |
|-----|------|
| `CustomOp` | 向量版自定义算子（推荐） |
| `TensorCustomOp` | 张量版自定义算子 |
| `AD.op(op, inputs)` | 应用自定义算子 |
| `AD.registerGradient()` | 已废弃：全局注册反向函数 |
| `AD.custom()` | 已废弃：创建自定义算子节点 |
