## 开场：GPS是如何实时估计位置的？

你在开车，GPS显示当前位置。但GPS信号有噪声，每秒更新一次。如何利用**上一秒的位置**和**这一秒的GPS读数**，实时估算最可靠的位置？

这就是**卡尔曼滤波**要解决的问题。

## 7.6.1 从信号滤波的角度理解卡尔曼滤波

### 7.6.1.1 一维信号滤波问题

假设我们测量一个缓慢变化的量（如温度），测量值 z[k] 含噪声：

$$

z[k] = x[k] + v[k]

$$

其中 x[k] 是真实值，v[k] ~ N(0, R) 是测量噪声。我们希望从 z[k] 中恢复 x[k]。

**直观想法**：用滑动平均？但这会引入延迟，且无法适应信号的变化速率。

卡尔曼滤波的核心思想：**利用信号的时间连续性**，在"预测"和"更新"之间迭代。

### 7.6.1.2 预测-更新两步循环

**预测步骤**：根据上一时刻的状态预测当前状态

$$

\hat{x}^{-}[k] = A \hat{x}[k-1] + Bu[k-1]

$$

其中 A 是状态转移矩阵，B 是控制矩阵。

**更新步骤**：用新的观测值校正预测

$$

K[k] = \frac{P^{-}[k]}{P^{-}[k] + R}  \quad \text{（卡尔曼增益）}

$$

$$

\hat{x}[k] = \hat{x}^{-}[k] + K[k](z[k] - H\hat{x}^{-}[k])

$$

其中 H 是观测矩阵，K[k] 是卡尔曼增益——它决定了我们应该多信任观测值。

> ⚠️ **常见误区**  
> 卡尔曼滤波假设噪声是高斯分布的。如果噪声是重尾分布（如拉普拉斯噪声），卡尔曼滤波会过于信任异常值，导致滤波效果下降。此时应考虑鲁棒滤波（如H∞滤波）。

## 7.6.2 状态空间模型

### 7.6.2.1 状态方程与观测方程

卡尔曼滤波基于**线性动态系统**的状态空间模型：

| 方程 | 形式 | 含义 |
|------|------|------|
| **状态方程** | x[k] = A x[k-1] + B u[k-1] + w[k-1] | 状态如何随时间演变 |
| **观测方程** | z[k] = H x[k] + v[k] | 我们能观测到什么 |

其中 w[k] ~ N(0, Q) 是过程噪声，v[k] ~ N(0, R) 是观测噪声。

### 7.6.2.2 协方差传播

预测误差的协方差：

$$

P^{-}[k] = AP[k-1]A^{\top} + Q

$$

更新误差的协方差：

$$

P[k] = (1 - K[k]H)P^{-}[k]

$$

**理解**：Q（R）越大→K越大→越信任观测（但也更受噪声影响）。

## 7.6.3 YiShape-Math API

### 7.6.3.1 一维卡尔曼滤波

```java
// 一维信号滤波
double[] measurements = {1.0, 1.1, 0.9, 1.05, 0.95, 1.02};
var filtered = Signals.kalman(measurements, 
    processNoise = 0.01,   // Q: 过程噪声方差
    measurementNoise = 0.1  // R: 观测噪声方差
);
// filtered: 滤波后的状态估计序列
```

### 7.6.3.2 参数选择指南

| 参数 | 含义 | 选择原则 |
|------|------|----------|
| Q（过程噪声）| 状态变化的预期方差 | Q大→滤波器响应快但噪声大 |
| R（观测噪声）| 测量设备的噪声方差 | R大→滤波器响应慢但更平滑 |

> 📝 **历史故事**  
> **Rudolf Kalman**（1930-2024）在1960年发明了卡尔曼滤波，最初用于阿波罗登月计划的轨道估计。NASA的工程师后来将离散卡尔曼滤波用于登月舱的导航系统。Kalman 本人在2024年1月去世，他发明的滤波器至今仍在 GPS、飞机导航、机器人定位、经济学时间序列分析中广泛使用。

### 7.6.3.3 二维位置-速度滤波

```java
// 二维目标跟踪（位置+速度）
// 状态: [x, y, vx, vy]，观测: [x, y]
var kf = Signals.kalman2D(
    initialState = new double[]{0, 0, 0, 0},  // x0, y0, vx0, vy0
    processNoise = 0.01,   // 过程噪声
    measurementNoise = 0.1 // 观测噪声
);

double[][] measurements = {{1.0, 1.0}, {2.1, 1.9}, {3.0, 3.1}};
for (double[] z : measurements) {
    var estimate = kf.update(z);  // 一步更新
    System.out.println(estimate[0] + ", " + estimate[1]);  // x, y 估计
}
```

## 7.6.4 扩展卡尔曼滤波（EKF）

当系统是**非线性**时，用泰勒展开线性化：

$$

f(x) \approx f(\hat{x}) + f'(\hat{x})(x - \hat{x})

$$

**EKF步骤**：
1. 计算非线性函数 f 和 h 的雅可比矩阵
2. 在预测点线性化
3. 应用标准卡尔曼滤波

```java
// EKF 用于非线性系统（需要用户提供 f 和 h 函数）
var ekf = Signals.extendedKalman(
    stateDim = 3,      // 状态维度
    obsDim = 2,        // 观测维度
    stateTransition = (x) -> { /* 非线性状态转移 */ },
    observation = (x) -> { /* 非线性观测函数 */ }
);
```

## 7.6.5 应用场景

### 7.6.5.1 GPS 定位

GPS接收机报告的位置有5-10米的随机误差。卡尔曼滤波通过融合多普勒速度测量（精度更高），将定位精度提升到1-2米。

### 7.6.5.2 金融时间序列去噪

股票价格受噪声驱动，真实价格（状态）是随机游走的。卡尔曼滤波可以实时估计"真实价格"，过滤高频噪声。

### 7.6.5.3 传感器融合

机器人同时有GPS、IMU（惯性测量单元）、轮式编码器三个传感器。卡尔曼滤波将三者融合，得到比任何单一传感器更精确的位置估计。
