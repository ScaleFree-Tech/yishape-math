## 二、新应用候选方案

### 候选 A：「设备健康预测——频谱分析与机器学习的交叉」

**问题描述**
旋转设备（电机、泵、齿轮箱）的振动信号包含丰富的健康信息。正常运行时振动频率固定；出现轴承磨损、不平衡、轴不对中时，会在特定频率出现异常能量峰值。本例从振动时序数据出发，用 FFT 提取频谱特征，再用 ML 分类器判断设备状态。

**数学模型**

```
训练数据：N 个样本，每个样本 = (FFT频谱向量, 健康标签)
特征：频谱幅度在特定频段的积分（故障特征频率）
模型：逻辑回归 或 随机森林（ML.logisticRegression / ML.randomForest）
评估：K 折交叉验证（ML.kFoldCrossValidation）
```

**用到的库模块**
| 模块 | 用途 |
|------|------|
| `Signals.sineWave` + 高斯噪声 | 生成模拟振动数据（含故障特征频率）|
| `ButterworthFilter` | 预处理（去趋势、去噪）|
| `SignalProcessorFactory.getInstance().createTransform("fft")` | 频谱计算 |
| `IVector` 操作 | 提取峰值频率、频段能量 |
| `ML.logisticRegression` | 二分类（正常/故障）|
| `ML.kFoldCrossValidation` | 评估模型泛化能力 |
| `Plots.line` | 绘制频谱图对比 |

**技术亮点**
- 这是现有教材极少覆盖的方向（传统 OR 教材不涉及信号处理）
- 真正体现了「数据→特征→决策」的端到端流程
- FFT 频谱图可直接用 `Plots.line` 可视化

**工作量评估**：★★☆（中等）
- 数据生成（模拟）+ FFT 特征提取 → ~50 行
- ML 训练与评估 → ~30 行
- 文档（含频谱可视化说明）→ ~200 行

### 候选 B：「投资组合优化——均值-CVaR 模型」

**问题描述**
传统 Markowitz 均值-方差模型以方差为风险度量。CVaR（Conditional Value at Risk，条件在险价值）相比方差是**一致风险测度**，更符合风险管理实践。本例在均值-CVaR 框架下，用历史收益率数据估计多元正态分布参数，再求解二次规划得到最优资产配置。

**数学模型**

```
给定：
  - N 种资产，历史收益率矩阵 R（N×T）
  - 预期收益率向量 μ = R 的列均值
  - 协方差矩阵 Σ = R 的列协方差

均值-CVaR 优化：
  min  CVaR_α(w)
  s.t. Σwᵢrᵢ ≥ r_min（最低收益约束）
       Σwᵢ = 1（权重和为1）
       wᵢ ≥ 0（禁止卖空）

CVaR_α(w) ≈ -1/(1-α) · E[min((w·r - τ), 0)]（Monte Carlo 近似）
其中 τ = VaR_α(w) 是分位数
```

**用到的库模块**
| 模块 | 用途 |
|------|------|
| `Stats.norm` | 生成模拟资产收益率数据 |
| `MultivariateNormalDistribution` | 资产联合分布建模 |
| `IVector.mean()` / `IVector.std()` | 估计参数 |
| `IMatrix` 协方差计算 | 风险估计 |
| `RereQPOptimizer` 或 `InteriorPointLinProgSolver` | 求解二次规划 |
| `Plots.line` | 绘制有效前沿曲线 |

**技术亮点**
- 均值-CVaR 是现代资产管理的工业标准（比方差更合理）
- 连接了统计分布估计与优化求解
- 可生成「有效前沿」曲线，直观展示收益-风险权衡

**工作量评估**：★★☆（中等）
- 数据生成 + 分布拟合 → ~30 行
- CVaR 优化问题建模 → ~60 行
- 有效前沿计算（多个风险厌恶参数）→ ~40 行
- 文档 → ~150 行

### 候选 C：「需求预测驱动的报童补货优化」

**问题描述**
在报童模型的基础上，增加**需求预测**环节：用时间序列分解从历史需求中提取趋势和季节性，用 Holt-Winters 预测下一期的需求分布，再据此计算最优订货量。体现「预测+优化」的两阶段决策流程。

**数学模型**

```
第一阶段（预测）：
  历史需求 d_1, d_2, ..., d_T → 时间序列分解
  → 趋势分量 T_t + 季节分量 S_t
  → Holt-Winters 预测下一期需求分布 N(μ_pred, σ_pred)

第二阶段（优化）：
  用预测的需求分布替代固定分布，重新计算临界比率
  Q* = F⁻¹((p+s-c)/(p+s))  （基于预测分布的分位数）
```

**用到的库模块**
| 模块 | 用途 |
|------|------|
| `Linalg` | 数据组织 |
| `TimeSeriesDecomposition.stlDecomposition` | STL 分解（趋势+季节+残差）|
| `Series.holtWintersForecast` | 需求预测 |
| `Stats.norm` | 预测需求分布建模 |
| `NewsvendorModel` | 最优订货量计算（复用现有模型）|
| `Plots.line` | 绘制历史需求、趋势、预测 |

**技术亮点**
- 两阶段决策（预测→优化）是供应链管理的核心范式
- 展示如何将 `TimeSeries` 模块与 `Optimization` 模块串联
- 现有报童模型只做单点估计，本例增加了预测维度

**工作量评估**：★★☆（中等）
- 时间序列分解 + Holt-Winters 预测 → ~40 行
- 两阶段决策逻辑 → ~30 行
- 对比图（有/无预测的决策差异）→ ~30 行
- 文档 → ~150 行

### 候选 D：「客户细分与差异化定价——GMM 聚类」

**问题描述**
企业有大量客户的历史行为数据（消费频率、平均订单额、折扣敏感度等）。用 GMM（高斯混合模型）对客户进行软聚类，将客户划分为多个细分群体，再针对每个群体设计差异化定价策略。GMM 的优势在于给出每个客户属于各群体的概率（软分配），比 K-Means 的硬划分更有商业价值。

**数学模型**

```
GMM 聚类：
  P(x) = Σₖ πₖ · N(x; μₖ, Σₖ)
  EM 算法估计参数 {πₖ, μₖ, Σₖ}

差异化定价：
  每个客户群体 k 有不同的价格敏感度 θₖ
  最优价格 pₖ* = argmax (p - c) · Φ(p; θₖ)
  其中 Φ 是该群体的需求函数
```

**用到的库模块**
| 模块 | 用途 |
|------|------|
| `Linalg.randn` | 生成模拟客户特征数据（多维）|
| `GaussianMixtureModel` | GMM 聚类 |
| `EMAlgorithm` | EM 算法训练 |
| `gmm.computePosteriors` | 计算每个客户的后验概率（软分配）|
| `RereLBFGS` | 求解各群体的最优价格 |
| `Plots.scatter` | 客户分布可视化（2D 投影）|
| `Plots.hist` | 各群体大小分布 |

**技术亮点**
- GMM 是市场细分的经典方法，比 K-Means 提供更多信息（概率而非硬标签）
- EM 算法的直观展示（与现有「Stats-Operations-EM 算法」文档完美对应）
- 软聚类结果可以直接用于精准营销

**工作量评估**：★★★（较高）
- 模拟数据生成（多维分布）→ ~30 行
- GMM 训练 + 后验概率计算 → ~40 行
- 差异化定价优化 → ~50 行
- 可视化 → ~30 行
- 文档 → ~200 行

### 候选 E：「多期生产计划与 workforce scheduling」

**问题描述**
制作业企业需要制定未来 T 期的生产计划，同时考虑招聘/解聘工人的调整成本。目标是确定每期的生产量和 workforce 水平，使总成本（生产成本 + 库存持有成本 + 招聘/解聘成本）最小。这是一个带跨期约束的线性规划问题，适合用 `RereSimplexLinProgSolver`。

**数学模型**

```
参数：
  D_t = 第 t 期需求（已知或预测）
  c_prod = 单位生产成本
  c_inv = 单位库存持有成本/期
  c_hire = 招聘一个工人的成本
  c_fire = 解聘一个工人的成本

决策变量：
  x_t = 第 t 期生产量
  h_t = 第 t 期招聘工人数
  f_t = 第 t 期解聘工人数
  w_t = 第 t 期 workforce 水平（工人数）

约束：
  x_t + inv_{t-1} - inv_t = D_t        （需求平衡）
  w_t = w_{t-1} + h_t - f_t             （workforce 平衡）
  inv_t ≥ 0, w_t ≥ 0, h_t ≥ 0, f_t ≥ 0 （非负约束）

目标：
  min Σ_t [c_prod·x_t + c_inv·inv_t + c_hire·h_t + c_fire·f_t]
```

**用到的库模块**
| 模块 | 用途 |
|------|------|
| `Linalg` | 构建 A 矩阵、b 向量 |
| `RereSimplexLinProgSolver` | 求解 LP（多期计划）|
| `OptResult.getOptimalPoint` | 提取最优生产计划 |
| `Plots.line` | 绘制生产计划时间线 |

**技术亮点**
- 线性规划是运筹学最经典的问题类型
- 多期 production planning 是 MRP（物料需求计划）系统的核心
- 规模适中，矩阵构建过程能清晰展示 LP 的建模思路

**工作量评估**：★☆☆（较低）
- 数据生成 + LP 建模 → ~50 行
- 求解 + 结果可视化 → ~30 行
- 文档 → ~150 行

## 三、综合评估与推荐

### 评估维度

| 候选 | 技术深度 | 库模块覆盖广度 | 教学价值 | 代码工作量 | 差异化特色 |
|------|---------|--------------|---------|---------|---------|
| A 设备健康预测 | 高（信号+ML）| 高（Signal+ML+Plots）| 高 | ★★☆ | ★★★★★（独特）|
| B 均值-CVaR 组合 | 高（统计+优化）| 中（Stats+LP/QP+Plots）| 高 | ★★☆ | ★★★★ |
| C 需求预测+报童 | 中（TS+Opt）| 中（TimeSeries+Stats+Opt）| 高 | ★★☆ | ★★★★ |
| D 客户细分（GMM）| 中（EM+ML+优化）| 高（GMM+EM+ML+Plots）| 高 | ★★★ | ★★★★ |
| E 多期生产计划 | 低（LP 建模）| 低（Linalg+LP）| 中 | ★☆☆ | ★★ |

### 推荐优先级

| 优先级 | 候选 | 核心理由 |
|-------|------|---------|
| **1（强烈推荐）** | **候选 A - 设备健康预测** | 真正体现了库的跨领域特色（信号处理+ML），绝大多数 OR 教材完全不涉及频谱分析，这是差异化最大、库利用率最高的候选 |
| **2（强烈推荐）** | **候选 B - 均值-CVaR 组合** | 现代资产管理的工业标准，比 Markowitz 更先进，可生成有效前沿可视化，CVaR 优化展示非线性规划能力 |
| **3（建议）** | **候选 D - 客户细分（GMM）** | 直接对应 Stats 文档中刚加的 GMM/EM 算法原理，形成「文档+示例」联动；GMM 软聚类比 K-Means 更适合商业场景 |
| **4（可选）** | 候选 C - 需求预测+报童 | 延伸了现有报童模型，但主要是「组合」而非「新方法」，差异化不够 |
| **5（可选）** | 候选 E - 多期生产计划 | 工作量最低，但 OR 教科书常见，且库模块覆盖较少 |

### 最终建议

**优先实现 A + B + D**（三个示例），分别对应：

```
A：设备健康预测（Signal + ML + Stats 联动）
B：投资组合 CVaR 优化（Stats 多元分布 + QP/LP + Visualization 联动）
D：客户细分 GMM（EM 算法 + 聚类 + 差异化优化 联动）
```

这三个示例覆盖了库的核心模块（Stats、GMM、ML、Signal、Opt、Plots），每一示例都有独特的技术视角，没有功能重叠，且都附带有丰富的可视化输出可以直观展示结果。
